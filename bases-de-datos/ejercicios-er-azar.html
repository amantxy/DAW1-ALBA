Ejercicios E-R al azar

Cómo se usa
  1. Pulsa + Entidad y escribe el nombre. Arrastra cada pieza con el dedo o el ratón.
  2. Con una entidad seleccionada, los botones de atributos crean el atributo ya unido a ella.
  3. Para unir dos piezas: toca una, pulsa Unir con… y toca la otra. Dos entidades se unen siempre con un rombo entre ellas.
  4. Al unir un rombo con una entidad, elige la cardinalidad junto a esa entidad. Por ejemplo, Propietario (1,1) — Posee — (1,n) Vehículo. La cardinalidad total, como 1:N, se calcula sola.
  5. Toca dos veces una pieza o una línea para editarla. Para una relación reflexiva, une el rombo dos veces con la misma entidad.
