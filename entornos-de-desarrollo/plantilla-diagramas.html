Cómo se usa

  1. Copia la plantilla como comentarios al principio del diagrama (o del pseudocódigo).
  2. Rellena los huecos con lo que dice el enunciado y borra los pasos que no necesites.
  3. Debajo de cada línea // coloca su figura (mira la tabla de equivalencias).
  4. Ejecútalo con el ejemplo del enunciado y con casos límite.

Plantilla universal

// ===== PLANTILLA UNIVERSAL =====
// 0. DATOS DEL ENUNCIADO (apúntalo antes de empezar)
//    ENTRAN (lo que se pregunta): ________________________________
//    SALEN (mensajes exactos):    ________________________________
//    CALCULO / RECUERDO:          ________________________________
//    ¿Se repite algo? NO / SÍ -> ¿al menos 1 vez? SÍ=Repetir  NO=Mientras  (nº fijo=Para)

// 1. DEFINIR variables
//    Definir ____ Como Entero      (números sin decimales, opciones 1-2-3, contadores)
//    Definir ____ Como Real        (decimales, dinero, kWh, km)
//    Definir ____ Como Caracter    (respuestas S/N)
//    Definir ____ Como Logico      (banderas: valido, hayautopista, horario...)

// 2. VALORES FIJOS E INICIALES (ANTES de cualquier bucle)
//    CONSTANTE_EN_MAYUSCULAS <- valor   (precios, porcentajes, límites)
//    contador <- 0 ; acumulador <- 0 ; bandera <- Falso

// 3. [BUCLE si hay] Repetir ... / Mientras condición Hacer ...
//    (si es Mientras: 1ª lectura ANTES del bucle y la siguiente al FINAL)

// 4. PEDIR DATOS (por cada dato: Escribir "mensaje exacto" + Leer variable)

// 5. VALIDAR
//    valido <- (dato1 en rango) Y (dato2 en rango) ...
//    Si NO valido -> "mensaje de error"
//    SiNo -> seguir con el paso 6

// 6. DECIDIR / CALCULAR
//    Varias opciones concretas (1, 2, 3) -> Según variable
//    Condiciones -> Si ... SiNo (de lo MÁS concreto a lo más general)
//    Cosas independientes -> Si separados, uno detrás de otro
//    Contar -> contador <- contador + 1 ; Sumar -> total <- total + cantidad

// 7. [FIN DEL BUCLE si hay]
//    Escribir "¿Otro...? (S/N)" ; Leer resp
//    Hasta Que resp <> "S" Y resp <> "s"   /   FinMientras

// 8. MOSTRAR RESULTADO (mensajes exactos, con la coma para juntar texto y variable)
//    Escribir "Texto: ", variable

// 9. PROBAR con el ejemplo del enunciado + casos límite (0, máximo, valores no válidos)
Preguntas rápidas para rellenarla:
1. ¿Qué me pide que pregunte? → variables + Leer.
2. ¿Qué tengo que calcular o contar? → variables + ←.
3. ¿El dato solo puede valer 1, 2, 3…? → Según. ¿Es una condición? → Si.
4. ¿Se repite? ¿Siempre al menos una vez? → Repetir. ¿Puede no hacerse? → Mientras.
5. ¿Qué mensajes exactos tengo que mostrar? → copiarlos tal cual del enunciado.

Los bucles

BucleSintaxisCuándoEjemplo
MientrasMientras condición Hacer … FinMientrasPuede ejecutarse 0 veces. Pregunta ANTES. Repite mientras la condición sea VERDADERA.Tramos del coche: Mientras distancia > 0 (1ª lectura antes, la siguiente al final)
RepetirRepetir … Hasta Que condiciónAl menos 1 vez. Pregunta DESPUÉS. Para cuando la condición es VERDADERA.Gimnasio, carga del coche, tragaperras
ParaPara i <- 1 Hasta 10 Con Paso 1 Hacer … FinParaSabes cuántas vueltas hay.«Pide 10 notas»
Truco: Mientras y Repetir usan condiciones contrarias: Mientras otro = "S" ≈ Hasta Que otro <> "S". Para darle la vuelta: = ↔ <>, < ↔ >=, > ↔ <=, Y ↔ O.

Ejemplos: la plantilla aplicada a las prácticas

Esquemas de las prácticas de diagramas de flujo (cine, tragaperras, gimnasio y coche eléctrico), listos para copiar.

Esquema general (sirve para cualquier ejercicio)
// 1. DEFINIR variables (qué pregunto + qué calculo) con su tipo
// 2. VALORES INICIALES (contadores a 0, valores fijos)
// 3. PEDIR DATOS (Escribir + Leer)
// 4. COMPROBAR que los datos son válidos
// 5. DECIDIR / CALCULAR (Si, Según)
// 6. BUCLE si algo se repite (Repetir si al menos 1 vez / Mientras si puede ser 0)
// 7. MOSTRAR resultado (mensajes exactos)
Ejercicio 1: Taquilla del cine
// DEFINIR: edad, dia, sala (Entero); carnetjoven (Caracter); valido (Logico); preciob, preciof, descuento (Real)
// PEDIR: "Edad:" -> edad
// PEDIR: "Dia de la semana (1 lunes ... 7 domingo):" -> dia
// PEDIR: "Sala (1 Normal, 2 3D, 3 VIP):" -> sala
// PEDIR: "Tiene carnet joven? (S/N):" -> carnetjoven
// valido <- Verdadero
// Si edad < 0 O edad > 120 -> valido <- Falso
// Si dia < 1 O dia > 7 -> valido <- Falso
// Si sala < 1 O sala > 3 -> valido <- Falso
// Si NO valido -> "Datos invalidos"
// SiNo:
//   Si sala = 3 Y edad < 16 -> "Entrada no permitida"
//   SiNo:
//     Según sala: 1 -> preciob 6.50 | 2 -> 8.50 | 3 -> 12.00
//     descuento <- 0
//     Si edad < 12 O edad >= 65 -> descuento <- preciob * 0.30
//     SiNo: Si carnet S/s Y edad 14..25 -> descuento <- preciob * 0.20
//     preciof <- preciob - descuento
//     Si dia = 3 Y sala <> 3 -> preciof <- preciof - 2
//     Si dia = 6 O dia = 7 -> preciof <- preciof + 1
//     MOSTRAR "Precio base: ", preciob
//     MOSTRAR "Precio final: ", preciof
Ejercicio 2: Tragaperras
// DEFINIR: creditos, tiradas, simb1, simb2, simb3 (Entero); eleccion (Caracter)
// creditos <- 10 ; tiradas <- 0
// MOSTRAR "Empiezas con ", creditos, " créditos"
// REPETIR (la primera tirada siempre se hace)
//   creditos <- creditos - 1 ; tiradas <- tiradas + 1
//   simb1, simb2, simb3 <- Azar(3) + 1   (da 1, 2 o 3)
//   MOSTRAR "Rodillos: ", simb1, " - ", simb2, " - ", simb3
//   Si los 3 = 3 -> "¡Premio gordo!" y creditos + 10
//   SiNo: Si simb1 = simb2 Y simb2 = simb3 -> "Tres iguales" y creditos + 5
//   SiNo: Si simb1=simb2 O simb1=simb3 O simb2=simb3 -> "Dos iguales" y creditos + 1
//   SiNo -> "Sin premio"
//   MOSTRAR "Créditos: ", creditos
//   Si creditos > 0 -> PEDIR "¿Otra tirada? (S/N):" -> eleccion
// HASTA QUE creditos <= 0 O (eleccion <> "S" Y eleccion <> "s")
// MOSTRAR "Tiradas realizadas: ", tiradas
// Si creditos <= 0 -> "Te has quedado sin créditos"
// SiNo -> "Te retiras con ", creditos, " créditos"
Ejercicio 3: Torno del gimnasio
// DEFINIR: abono, dia, hora, permitidos, denegados (Entero); cuota, otro (Caracter); valido, horario (Logico)
// permitidos <- 0 ; denegados <- 0   (FUERA del bucle)
// REPETIR (siempre pasa al menos un socio)
//   PEDIR "Tipo de abono (1 Mañana, 2 Tarde, 3 Completo):" -> abono

//       Si dia = 7 -> horario <- hora >= 9 Y hora < 14
//       SiNo: Según abono: 1 -> 7..<15 | 2 -> 15..<23 | 3 -> 7..<23

Ejercicio 4: Coche eléctrico
