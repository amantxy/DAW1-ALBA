2. Pseudocódigo

Escribe la solución tú antes de abrirla. Luego compara.

1. Media de cinco notas y aprobadoMedio

Lee cinco notas, muestra su media y escribe «Aprobado» si la media es 5 o más, o «Suspenso» si no.

Pista. Usa una variable suma que acumule las notas y un Para de 1 a 5. Después calcula la media dividiendo entre 5.

Ver soluciónMedia de cinco notas y aprobado
Proceso Notas
  Definir i, nota, suma, media Como Real
  suma<-0
  Para i<-1 Hasta 5 Hacer
    Escribir "Nota ", i, ": " Sin Saltar
    Leer nota
    suma<-suma+nota
  FinPara
  media<-suma/5
  Escribir "Media: ", media
  Si media>=5 Entonces
    Escribir "Aprobado"
  SiNo
    Escribir "Suspenso"
  FinSi
FinProceso
2. El mayor de tres númerosMedio

Lee tres números distintos y muestra cuál es el mayor.

Pista. Compara el primero con el segundo y el ganador con el tercero. Con Si y Sino Si puedes cubrir todos los casos.

Ver soluciónEl mayor de tres números
Proceso Mayor
  Definir a, b, c, m Como Real
  Leer a, b, c
  Si a>=b Y a>=c Entonces
    m<-a
  SiNo
    Si b>=c Entonces
      m<-b
    SiNo
      m<-c
    FinSi
  FinSi
  Escribir "El mayor es ", m
FinProceso
3. Contar pares hasta leer un 0Medio-difícil

Lee números enteros hasta que el usuario introduzca un 0. Al final muestra cuántos han sido pares. El 0 no cuenta.

Pista. El bucle debe leer antes de comprobar, así que una forma sencilla es leer un número fuera del bucle y otro dentro. Usa Mientras con la condición num<>0.

Ver soluciónContar pares hasta leer un 0
Proceso ContarPares
  Definir num, pares Como Entero
  pares<-0
  Escribir "Introduce un número (0 para acabar):"
  Leer num
  Mientras num<>0 Hacer
    Si num MOD 2 = 0 Entonces
      pares<-pares+1
    FinSi
    Leer num
  FinMientras
  Escribir "Pares: ", pares
FinProceso
4. Pedir una nota válida con RepetirDifícil

Pide una nota entre 0 y 10. Si el usuario escribe un valor fuera de ese rango, vuelve a pedirla hasta que sea válida. Después muestra la nota.

Pista. Repetir Hasta se ejecuta al menos una vez, perfecto para validar. La condición de salida es que la nota esté entre 0 y 10.

Ver soluciónPedir una nota válida con Repetir
Proceso NotaValida
  Definir nota Como Real
  Repetir
    Escribir "Nota (0 a 10):"
    Leer nota
  Hasta Que nota>=0 Y nota<=10
  Escribir "Nota válida: ", nota
FinProceso
5. Calculadora con SegunMedio

Pide dos números y una opción: 1 suma, 2 resta, 3 multiplica, cualquier otra cosa muestra «Opción no válida».

Pista. Segun opcion Hacer … De Otro Modo … FinSegun. Recuerda que el Segun compara el valor de una sola variable.

Ver soluciónCalculadora con Segun
Proceso Calculadora
  Definir a, b, r Como Real
  Definir op Como Entero
  Leer a, b
  Escribir "1 suma, 2 resta, 3 multiplica:"
  Leer op
  Segun op Hacer
    1: r<-a+b
    2: r<-a-b
    3: r<-a*b
    De Otro Modo: Escribir "Opción no válida"
  FinSegun
  Escribir "Resultado: ", r
FinProceso
3. Diagramas de flujo

Los diagramas se dibujan con estos símbolos: óvalo (inicio y fin), rectángulo (proceso), paralelogramo (entrada y salida) y rombo (decisión). En las soluciones usamos texto para que se vea la estructura.

6. Diagrama: suma, resta y producto de dos númerosFácil

Dibuja el diagrama que lee dos números y muestra su suma, su resta y su producto.

Pista. Sigue el orden: Inicio, Leer, tres cálculos o salidas, Fin. Cada paso es un símbolo distinto.

Ver soluciónDiagrama: suma, resta y producto de dos números
[ Inicio ]  (óvalo)
      |
[ Leer a, b ]  (paralelogramo)
      |
[ r1 <- a + b ]  (rectángulo)
      |
[ Escribir r1 ]  (paralelogramo)
      |
[ r2 <- a - b ]
      |
[ Escribir r2 ]
      |
[ r3 <- a * b ]
      |
[ Escribir r3 ]
      |
[ Fin ]  (óvalo)
7. Diagrama: clasificar por edadMedio

Lee una edad. Si es menor de 18, escribe «Menor»; si está entre 18 y 64, escribe «Adulto»; si es 65 o más, escribe «Mayor».

Pista. Usa dos rombos seguidos. El primero separa menores; el segundo, adultos y mayores.

Ver soluciónDiagrama: clasificar por edad
[ Inicio ]
   |
[ Leer edad ]
   |
<edad < 18 ?> --Sí--> [ Escribir "Menor" ] --> [ Fin ]
   | No
<edad < 65 ?> --Sí--> [ Escribir "Adulto" ] --> [ Fin ]
   | No
[ Escribir "Mayor" ] --> [ Fin ]
8. Diagrama con bucle: suma de 1 a NDifícil

Lee un número N y calcula la suma de todos los números del 1 al N. Dibuja el bucle con un rombo de control.

Pista. Necesitas tres variables: i (contador), suma y N. El rombo comprueba si i sigue siendo menor o igual que N, y la flecha de retorno vuelve a él.

Ver soluciónDiagrama con bucle: suma de 1 a N
[ Inicio ]
   |
[ Leer N ]
   |
[ suma <- 0 ; i <- 1 ]
   |
<i <= N ?> --No--> [ Escribir suma ] --> [ Fin ]
   | Sí
[ suma <- suma + i ]
   |
[ i <- i + 1 ]
   |
   +--(vuelve al rombo)
4. Errores típicos
  • Olvidar que el Segun compara una variable con varios valores, y Si con Y/O compara condiciones.
  • Usar = para asignar: en PSeInt la asignación es <- y la comparación es =.
  • Repetir Hasta cumple la condición al revés: el bucle sigue mientras la condición es falsa.
  • Dejar un contador sin inicializar (sin poner a 0 antes del bucle).
  • En diagramas, olvidar la flecha de vuelta al rombo de control del bucle.
  • Poner la lectura dentro del Mientras sin volver a leer al final (el bucle no avanza).
5. Ayudas y reglas nemotécnicas
Ciclo de vida

Análisis, Diseño, Codificación, Pruebas, Mantenimiento: «Ana Diseña Código, Prueba y Mantiene».

Cascada

Etapas en fila, como una cascada: no empiezas una hasta acabar la anterior. Con realimentación puedes volver atrás.

Incremental

«Incremento» = pequeñas partes que sirven. Entregas cada parte y la siguiente se suma a la anterior.

Espiral

Da vueltas y en cada vuelta mira los riesgos: «la espiral analiza riesgos».

Tipos de software

Sistema = hace funcionar el hardware (SO). Aplicación = tarea concreta (Word, CAD). Programación = herramientas para programar (IDE).

Shareware

«Share» = compartes para probar; luego pagas. Freeware = gratis, pero no modificar ni vender.

Adware

«Ad» = anuncio: se descarga publicidad al ejecutarse.

Software libre

Cuatro libertades: usar, estudiar, distribuir y mejorar. Necesita código fuente. Licencia típica: GPL.

Software propietario

«Propiedad»: se da en binario, sin código fuente, y el dueño prohíbe copiar o modificar.

Dominio público

«Es de todos»: sin licencia o autor desconocido; se puede usar libremente.

Nombres en Java

Clases con mayúscula (HiloServidor). Métodos camelCase (ejecutar). Constantes MAYÚSCULAS_CON_GUION. Paquetes en minúscula (java.io).

Formato Java

Sangría de 4 espacios, 80 caracteres por línea de código (70 en comentarios). Una variable por línea.

Comentarios Java

/** */ = documentación (va justo antes de la clase o método, lo lee Javadoc). /* */ y // = implementación.

Ficheros Java

Extensión .java al escribir y .class al compilar. Un solo public class por fichero, y debe ser la primera clase.

PSeInt: asignar y comparar

Asignar es <- (flecha que mete el valor). Comparar es = (signo igual). Definir x Como Real declara la variable.

PSeInt: MOD y DIV

MOD = resto (7 MOD 3 = 1). DIV = división entera (7 DIV 2 = 3). «MOD mira lo que sobra».

Mientras vs Repetir

Mientras comprueba antes (puede no entrar). Repetir comprueba después: entra al menos una vez.

Y / O

Y (AND) = tienen que cumplirse las dos. O (OR) = basta con una.

Diagramas: símbolos

Óvalo = inicio/fin (una pastilla). Rombo = decisión, dos salidas Sí/No. Rectángulo = proceso. Paralelogramo = entrada/salida de datos.

Diagramas: bucle

Si el rombo vuelve hacia atrás, es un bucle. Antes de volver, pon el contador a 0 y súmale en cada vuelta.

8. Resúmenes de los PDF originales

UT1 · Software, licencias y ciclo de vida

PDF «UT1: Desarrollo de software», apartados 1.1 a 1.3
  • Hardware: componentes que se pueden tocar. Software: programas, instrucciones y reglas; según IEEE 729 incluye también documentación y datos.
  • Por tarea: software de sistema (permite que el hardware funcione: SO, controladores), de aplicación (tareas concretas: ofimática, CAD) y de programación (IDE).
  • Por distribución: shareware (evaluación limitada y luego pagas), freeware (sin cargo, con restricciones: no modificar ni vender; no es software libre), adware (publicidad) y uso específico.
  • Licencia: contrato que fija los derechos y deberes de desarrollador y usuario.
  • Software libre: cede cuatro libertades (usar, estudiar, distribuir, mejorar) y exige código fuente. Licencia más usada: GPL, que obliga a hacer públicas las versiones modificadas.
  • Propietario: binario sin código fuente, con copia y modificación prohibidas. Dominio público: sin licencia o autor desconocido; se puede usar libremente.
  • Ciclo de vida (ISO/IEC 12207-1): cada etapa recibe documentos de la anterior y produce documentos nuevos.
  • Cascada: etapas secuenciales; la variante con realimentación permite volver atrás. Incremental: entrega partes utilizables. Espiral: cascada con prototipos y análisis de riesgos en cada ciclo.
RecuerdaSoftware libre no es lo mismo que freeware. El modelo en espiral es el que incorpora análisis de riesgos en cada ciclo.

UT1 · Fases, máquina y lenguajes

PDF «UT1: Desarrollo de software», apartados 1.4 a 1.8
  • Fases: análisis, diseño, codificación, pruebas, documentación, explotación y mantenimiento.
  • Análisis: requisitos funcionales (qué hace) y no funcionales (fiabilidad, plataforma, restricciones). Herramientas: DFD, DFC, DTE, DER y diccionario de datos.
  • Diseño: estructurado (datos, arquitectura, interfaz y procedimientos; secuencial, condicional y repetitiva) u orientado a objetos (cuatro capas, UML).
  • Pruebas: verificación (¿lo construimos bien?) y validación (¿construimos lo que pidió el cliente?). Caja blanca frente a caja negra. Una prueba tiene éxito si descubre un error.
  • Mantenimiento (IEEE 1219): correctivo, adaptativo (el más usual), perfectivo y preventivo.
  • Von Neumann: la CPU tiene UC (control), UAL (cálculo y comparaciones) y registros (CP, RI, RDM, RIM). Ciclo fetch-execute.
  • Lenguajes: léxico, sintaxis y semántica. Según el nivel: máquina, ensamblador, medio (C) y alto (Java, Python).
  • Compilador (traduce todo; si hay errores no genera código objeto) frente a intérprete (traduce y ejecuta al momento). Java combina ambos: .java → bytecode (.class) → JVM.
RecuerdaCompilación: léxico → sintáctico → semántico → generación y optimización. Código fuente → objeto → ejecutable (enlazador).

PSeInt · Manual «From Zero to Hero»

Algoritmos, datos, condiciones, ciclos, arreglos y subprocesos
  • Algoritmo: secuencia ordenada y precisa de pasos. Entrada → proceso → salida. Usa el perfil Estricto.
  • Variables y tipos: Definir x Como Entero, Real, Logico, Caracter o Cadena (texto). Declarar no es asignar: da un valor antes de usarla.
  • Asignación <- (primero se calcula la derecha). Operadores: + − * / ^ MOD (resto) y paréntesis. 7 MOD 2 = 1.
  • Entrada y salida: Escribir pide o muestra; Leer guarda lo que introduces; Sin Saltar evita el salto de línea.
  • Condiciones: =, <>, <, >, <=, >=. Y exige ambas; O basta una; NO invierte. Si … Entonces … Sino … FinSi y Segun … De Otro Modo … FinSegun.
  • Ciclos: Mientras comprueba antes (puede hacer 0 vueltas); Repetir … Hasta Que comprueba después (al menos 1); Para i <- 1 Hasta n Con Paso p si conoces las vueltas.
  • Arreglos y matrices: con Dimension y base 0 (la primera casilla es la 0). Una matriz tiene dos índices: tabla[fila,columna].
  • Subprocesos: agrupan tareas con nombre y pueden recibir parámetros o devolver un valor. Se definen fuera de Proceso Principal.
RecuerdaContador: c <- c + 1, puesto a 0 antes del bucle. Acumulador: suma <- suma + numero, también a 0 antes. Si olvidas aumentar el contador en Mientras, el ciclo no termina.
