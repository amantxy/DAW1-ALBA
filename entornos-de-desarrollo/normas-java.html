Normas de codificación en Java

En cualquier proyecto en el que trabaja un grupo de personas debe haber unas normas de codificación y estilo, claras y homogéneas. Estas normas facilitan las tareas de corrección y mantenimiento de los programas, sobre todo cuando son realizadas por personas que no los han desarrollado.

Nombres de ficherosExtensiones .java y .class

La extensión para los ficheros de código fuente es .java y para los ficheros compilados es .class.

Organización de ficherosComentarios, package, import y clases

Cada fichero debe contener una sola clase pública y debe ser la primera. Las clases privadas e interfaces asociados con esa clase pública se pueden poner en el mismo fichero después de la clase pública. Las secciones en las que se divide el fichero son:

Comentarios. Todos los ficheros fuente deben comenzar con un comentario que muestra el nombre de la clase, información de la versión, la fecha y el aviso de derechos de autor. Formato: /* Nombre de clase / Información de la versión / Fecha / Aviso de Copyright */

Sentencias package e import. Van después de los comentarios; package va delante de import. Ejemplo:

/*
 * Nombre de clase
 *
 * Información de la versión
 *
 * Fecha
 * Aviso de Copyright */

package paquete.ejemplo;

import java.io.*;

Declaraciones de clases e interfaces. Consta de:

  1. Comentario de documentación /** ... */ de la clase o interfaz.
  2. Sentencia class o interface.
  3. Comentario de implementación /* ... */.
  4. Variables estáticas: públicas, protegidas, privadas.
  5. Variables de instancia: públicas, protegidas, privadas.
  6. Constructores.
  7. Métodos agrupados por funcionalidad, no por alcance.
IdentaciónEspacios y longitud de línea
  • Se usarán cuatro espacios.
  • Líneas de código: máx. 80 caracteres.
  • Líneas de comentarios: máx. 70 caracteres.
ComentariosDe documentación y de implementación

Los comentarios deben contener sólo la información que es relevante para la lectura y la comprensión del programa. Existen dos tipos:

Comentarios de documentación. Destinados a describir la especificación del código. Se utilizan para describir las clases Java, interfaces, constructores, métodos y campos. Deben aparecer justo antes de la declaración. La herramienta Javadoc genera páginas HTML a partir de este tipo de comentarios.

/**
 * La clase Ejemplo proporciona ...
 */
public class Ejemplo { ... }

Comentarios de implementación. Para comentar detalles de la aplicación particular. Puede ser de 3 tipos:

  • Comentarios de bloque: /* Esto es un comentario de bloque */
  • Comentarios de línea: /* Esto es un comentario de línea */
  • Comentario corto: // Esto es un comentario corto

SentenciasBloques, if, bucles y return
  • Cada línea debe contener una sentencia.
  • Si hay un bloque de sentencias, éste debe ser sangrado con respecto a la sentencia que lo genera y debe estar entre llaves, aunque sólo tenga una sentencia.
  • Sentencias if-else, if else-if else. Definen bloques a los que se aplican las normas anteriores. Todos los bloques tienen el mismo nivel de sangrado.
  • Bucles. Definen un bloque, que sigue las normas anteriores. Si el bucle está vacío no se abren ni se cierran llaves.
  • Las sentencias return no deben usar paréntesis.
SeparacionesLíneas y espacios en blanco

Dos líneas en blanco entre clases. Una línea en blanco entre métodos y secciones lógicas. Un espacio en blanco tras comas y operadores binarios.

NombresPaquetes, clases, métodos, variables y constantes

Paquetes en minúscula (java.io). Clases con mayúscula inicial (HiloServidor). Métodos en camelCase (ejecutar(), asignarDestino()). Variables cortas (i, sumaTotal). Constantes en MAYÚSCULAS_CON_GUIÓN (MAX_VALOR).

Ejemplo con y sin formatoEl mismo programa, dos lecturas

Estos dos programas son el mismo, pero uno resulta más fácil de leer:

Sin formato:

public class Ejemplo
{ public static void main(String[] args)
{ int suma=0; int contador=0;
while(contador<10){contador++;
suma=suma+contador;}
System.out.println("Suma => "+suma);}}

Con formato:

public class Ejemplo {
    public static void main(String[] args) {
        int suma = 0;
        int contador = 0;
        while (contador < 10) {
            contador++;
            suma = suma + contador;
        }
        System.out.println("Suma => " + suma);
    }
}
