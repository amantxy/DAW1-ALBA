El programa principal

Todo programa Java se escribe dentro de una clase y empieza a ejecutarse en el método main. El algoritmo va dentro de sus llaves.

package miprimerprograma;

public class MiPrimerPrograma {
    public static void main(String[] args) {
        // aquí va el algoritmo
    }
}

En NetBeans se ejecuta con Run Project (F6).

Variables e identificadores

Una variable es un nombre (identificador) asociado a un valor que puede cambiar. Se le da valor con la asignación =.

a = 10;
b = a + 1;   // b vale 11

Reglas de los identificadores

  • Empiezan por letra, _ o $.
  • Los siguientes caracteres: letras, dígitos, _ o $.
  • No pueden ser palabras reservadas.
  • Distinguen mayúsculas de minúsculas (edad ≠ Edad).
  • No hay longitud máxima.
Notación Camel: edad, maxValor, notaMediaTercerTrimestre.

Operadores

Asignación

variable = expresión; (el valor puede ser un literal, otra variable o una expresión).

Aritméticos

+ - * / % y también ++ / -- (prefijo o postfijo). 7 % 3 = 1 (resto).

Relacionales

== != < <= > >=

No confundir = (asigna) con == (compara).

Lógicos

&& (y), || (o), ! (no).

Ternario

UT 2 · Estructuras de control

Fuente: U2 Estructuras de control.pdf del profesor.

Introducción

Las estructuras de control alteran el flujo secuencial del programa (por defecto, línea a línea). Las instrucciones se agrupan en bloques con llaves { }.

Alternativas: if, if-else, anidados

if simple

if (condición) {
    // se ejecuta si es true
}

if-else

if (sueldo < 1000) {
    sueldo = sueldo * 1.15;
} else {
    sueldo = sueldo * 1.12;
}

Escala if-else (varias alternativas)

if (0 <= nota && nota < 5) {
    System.out.println("Insuficiente");
} else if (nota < 6) {
    System.out.println("Suficiente");
} else if (nota < 9) {
    System.out.println("Notable");
} else {
    System.out.println("Sobresaliente");
}
Otro ejemplo del tema: calcular el valor absoluto con if (x < 0) x = -x;.

switch

La expresión puede ser int, byte, short, char o String. default es opcional.

switch clásico

switch (dia) {
    case 1:  System.out.println("Lunes");   break;
    case 2:  System.out.println("Martes");  break;
    default: System.out.println("Otro día");
}
Sin break hay fall-through: se siguen ejecutando los case siguientes.

El fall-through sirve para agrupar cases:

switch (mes) {
    case 1: case 3: case 5: case 7: case 8: case 10: case 12:
        System.out.println("31 días"); break;
    case 2:
        System.out.println("28 días"); break;
    default:
        System.out.println("30 días");
}

switch moderno (con ->, sin break)

switch (mes) {
    case 1, 3, 5, 7, 8, 10, 12 -> System.out.println("31 días");
    case 2 -> System.out.println("28 días");
    default -> System.out.println("30 días");
}

while y do-while

while (precondición)

Comprueba la condición antes; puede ejecutarse 0 veces.

int i = 1;
while (i <= 3) {
    System.out.println(i);
    i++;
}
// cuerpo vacío: raíz cuadrada entera
while (++sqrt * sqrt != target) ;

do-while (poscondición)

Comprueba después; se ejecuta al menos una vez. Termina en ;.

int i = 1;
do {
    System.out.println(i);
    i++;
} while (i <= 10);

for

for (inicialización; condición; incremento) {
    // cuerpo
}

for (int i = 1; i <= 5; i++) {
    System.out.println(i);
}

Secuencia de control: 1) inicialización (una vez) → 2) condición → 3) cuerpo → 4) incremento → vuelve a 2. Sale cuando la condición es false.

break y continue

  • break: sale del bucle (o del switch) inmediatamente.
  • continue: salta a la siguiente iteración.
for (int i = 1; i <= 10; i++) {
    if (i == 3) continue;  // se salta el 3
    if (i == 6) break;     // termina en el 6
    System.out.println(i); // 1 2 4 5
}

1. Estructura de un método

En Java las funciones se llaman métodos y se declaran dentro de una clase. Sirven para organizar, reutilizar y dividir un problema en tareas pequeñas.

public static int sumar(int a, int b) {
    return a + b;
}

2. Declarar y llamar

Declarar = escribir qué hace. Llamar = ejecutarlo.

public class Ejemplo {
    public static int sumar(int a, int b) { return a + b; }

    public static void main(String[] args) {
        int resultado = sumar(4, 6);
        System.out.println(resultado); // 10
    }
}
Parámetros = variables de la declaración (a, b). Argumentos = valores que se pasan al llamar (4, 6).

3. Tipos de método según parámetros y retorno

Sin parámetros y sin retorno (void)

public static void saludar() { System.out.println("¡Hola!"); }
saludar();

Con parámetros y sin retorno

public static void saludarPersona(String nombre) {
    System.out.println("Hola, " + nombre);
}
saludarPersona("Ana");

Sin parámetros y con retorno

public static int obtenerNumero() { return 10; }
int numero = obtenerNumero();

Con parámetros y con retorno

public static double calcularArea(double base, double altura) {
    return base * altura / 2;
}
double area = calcularArea(6, 4); // 12.0

Suma con función: PSeInt vs Java

Objetivo: pedir dos enteros, llamar a una función que los sume y mostrar el resultado. El programa principal lee y muestra; la función calcula.

PSeInt

    Definir resultado Como Entero
    resultado <- a + b
FinFuncion

Algoritmo Principal
    Definir num1, num2, suma Como Entero
    Escribir "Introduce el primer número:"
    Leer num1
    Escribir "Introduce el segundo número:"
    Leer num2
    suma <- Sumar(num1, num2)
    Escribir "La suma es: ", suma
FinAlgoritmo

En PSeInt, la variable a la izquierda de <- en la cabecera es la que se devuelve.

Java

import java.util.Scanner;

public class Principal {
    public static int sumar(int a, int b) {
        int resultado = a + b;
        return resultado;
    }
    public static void main(String[] args) {
        Scanner teclado = new Scanner(System.in);
        int num1, num2, suma;
        System.out.print("Introduce el primer número: ");
        num1 = teclado.nextInt();
        System.out.print("Introduce el segundo número: ");
        num2 = teclado.nextInt();
        suma = sumar(num1, num2);
        System.out.println("La suma es: " + suma);
    }
}
  • import java.util.Scanner; permite leer del teclado.
  • new Scanner(System.in) crea el lector; nextInt() lee un entero.
  • print no salta de línea; println sí.

4. Cómo funciona return

return termina el método en ese momento. El valor debe ser compatible con el tipo de retorno.

public static boolean esPar(int numero) {
    return numero % 2 == 0;
}

Un método con retorno debe devolver valor en todos los caminos:

public static String comprobarEdad(int edad) {
    if (edad >= 18) {
        return "Mayor de edad";
    }
    return "Menor de edad";
}

En un void se puede usar return; para salir antes:

public static void mostrarDivision(double a, double b) {
    if (b == 0) {
        System.out.println("No se puede dividir entre cero");
        return;
    }
    System.out.println(a / b);
}
Mostrar ≠ devolver: println escribe en pantalla; return entrega un resultado al código que llamó.

5. Métodos static y de instancia

Un método static se llama con el nombre de la clase:

public class Calculadora {
    public static int multiplicar(int a, int b) { return a * b; }
}
int resultado = Calculadora.multiplicar(3, 4);

Uno de instancia necesita un objeto:

public class Persona {
    public void saludar() { System.out.println("¡Hola!"); }
}
Persona persona = new Persona();
persona.saludar();

Desde main (que es static) necesitas un objeto para llamar a un método de instancia.

6. Sobrecarga de métodos

Varios métodos con el mismo nombre si cambia el número, el tipo o el orden de los tipos de los parámetros.

public static int sumar(int a, int b)           { return a + b; }
public static double sumar(double a, double b)  { return a + b; }
public static int sumar(int a, int b, int c)    { return a + b + c; }

sumar(2, 3);       // 5
sumar(2.5, 3.5);   // 6.0
sumar(2, 3, 4);    // 9
Cambiar solo el tipo de retorno no permite sobrecargar.

7. Ámbito de las variables

Parámetros y variables locales solo existen dentro de su método.

public static int duplicar(int numero) {
    int resultado = numero * 2;
    return resultado;
}
// fuera no existen numero ni resultado
int doble = duplicar(5);   // recoge el valor devuelto

8. Paso de argumentos por valor

Java siempre pasa por valor: el método recibe una copia.

public static void cambiar(int numero) { numero = 100; }
int valor = 5;
cambiar(valor);
System.out.println(valor);   // 5

Con objetos y arrays se copia la referencia, así que el método sí puede modificar el contenido:

public static void cambiarPrimero(int[] numeros) { numeros[0] = 100; }
int[] datos = {1, 2, 3};
cambiarPrimero(datos);
System.out.println(datos[0]);   // 100

Pero asignar un objeto nuevo al parámetro no cambia la variable del llamador.

9. Recursividad

Un método es recursivo si se llama a sí mismo. Necesita un caso base que detenga las llamadas.

// válido para n entre 0 y 12
public static int factorial(int n) {
    if (n < 0 || n > 12) {
        throw new IllegalArgumentException("n debe estar entre 0 y 12");
    }
    if (n == 0) {
        return 1;               // caso base
    }
    return n * factorial(n - 1);
}
factorial(4);   // 4 × 3 × 2 × 1 = 24

El límite 12 evita que el resultado supere la capacidad de int.

10. Errores frecuentes

  • Olvidar devolver valor en un método que no es void.
  • Confundir imprimir con devolver.
  • Pasar argumentos con tipos o cantidad incorrectos.
  • Llamar a un método de instancia desde main sin crear un objeto.
  • Declarar un método dentro de otro.
  • Creer que cambiar un parámetro primitivo modifica la variable original.
