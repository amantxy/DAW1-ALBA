El programa principal

Todo programa Java se escribe dentro de una clase y empieza a ejecutarse en el método main. El algoritmo va dentro de sus llaves.

package miprimerprograma;

public class MiPrimerPrograma {
    public static void main(String[] args) {
        // aquí va el algoritmo
    }
}

En NetBeans se ejecuta con Run Project (F6).

Variables e identificadores

Una variable es un nombre (identificador) asociado a un valor que puede cambiar. Se le da valor con la asignación =.

a = 10;
b = a + 1;   // b vale 11

Reglas de los identificadores

  • Empiezan por letra, _ o $.
  • Los siguientes caracteres: letras, dígitos, _ o $.
  • No pueden ser palabras reservadas.
  • Distinguen mayúsculas de minúsculas (edad ≠ Edad).
  • No hay longitud máxima.
Notación Camel: edad, maxValor, notaMediaTercerTrimestre.

Introducción a la programación (conceptos)

Fuente: Introduccion_a_la_Programacion_Informatica.docx

Programar es transformar una solución lógica en instrucciones que un ordenador pueda ejecutar. Las instrucciones deben ser precisas: qué datos usar, qué operaciones, en qué orden, qué decisiones y qué resultado.

Problema → Análisis → Algoritmo → Código fuente → Ejecución → Resultado
ConceptoQué es
ProgramaConjunto organizado de instrucciones para resolver una tarea.
ProgramaciónProceso completo: analizar, diseñar, crear el algoritmo, codificar, ejecutar, depurar, mantener.
Lenguaje de programaciónSímbolos, palabras reservadas y reglas sintácticas para expresar instrucciones.
Código fuenteTexto con las instrucciones escritas en un lenguaje (.java, .py…).

Modelo Entrada → Proceso → Salida

Ejemplo: precio final con descuento. Entrada: precio y % descuento. Proceso: calcular el descuento y restarlo. Salida: precio final.

Fases

  1. Análisis del problema
  2. Diseño de la solución
  3. Codificación
  4. Pruebas (valores normales, límites y casos especiales)
  5. Corrección de errores (depuración / debugging)
  6. Mantenimiento

Algoritmo

Secuencia ordenada, precisa y finita de instrucciones que resuelve un problema. Debe ser preciso, ordenado, finito y definido; con los mismos datos de entrada da el mismo resultado.

Inicio
  Leer nota1
  Leer nota2
  Leer nota3
  suma = nota1 + nota2 + nota3
  media = suma / 3
  Mostrar media
Fin

Pseudocódigo

Representa algoritmos con expresiones parecidas al lenguaje natural pero estructuradas, sin ser de ningún lenguaje concreto. Permite centrarse en la lógica, detectar errores antes de programar y comunicar soluciones. Palabras habituales: Inicio, Fin, Leer, Escribir, Si, Entonces, SiNo, FinSi, Mientras, FinMientras, Para, FinPara.

Java: estructura básica, salida y entrada

Fuente: Estructura básica de un programa en Java.pdf

public class HolaMundo {
    public static void main(String[] args) {
        System.out.println("Hola Mundo");
    }
}
  • Todo programa Java está dentro de una clase. El nombre de la clase pública debe coincidir con el del archivo (HolaMundo.java).
  • main: punto de entrada. public (accesible), static (sin crear objeto), void (no devuelve nada), String[] args (parámetros de la línea de comandos).
  • Las llaves { } delimitan la clase y el método.

Salida

System.out.println("Hola");   // con salto de línea
System.out.print("Hola ");    // sin salto de línea
System.out.print("Mundo");    // Hola Mundo

Entrada con Scanner

import java.util.Scanner;

public class EntradaSalida {
    public static void main(String[] args) {
        Scanner sc = new Scanner(System.in);

        System.out.print("Escribe tu nombre: ");
        String nombre = sc.nextLine();      // línea de texto
        System.out.print("Escribe tu edad: ");
        int edad = sc.nextInt();            // entero
        System.out.print("Escribe tu altura (ej: 1.75): ");
        double altura = sc.nextDouble();    // decimal

        System.out.println("\n--- RESULTADOS ---");
        System.out.println("Nombre: " + nombre);
        System.out.println("Edad: " + edad + " años");
        System.out.println("Altura: " + altura + " m");
        sc.close();                         // buena práctica
    }
}

Fuente: U2 Estructuras de control.pdf del profesor.

Introducción

Las estructuras de control alteran el flujo secuencial del programa (por defecto, línea a línea). Las instrucciones se agrupan en bloques con llaves { }.

Alternativas: if, if-else, anidados

if simple

if (condición) {
    // se ejecuta si es true
}

if-else

if (sueldo < 1000) {
    sueldo = sueldo * 1.15;
} else {
    sueldo = sueldo * 1.12;
}

Escala if-else (varias alternativas)

if (0 <= nota && nota < 5) {
    System.out.println("Insuficiente");
} else if (nota < 6) {
    System.out.println("Suficiente");
} else if (nota < 9) {
    System.out.println("Notable");
} else {
    System.out.println("Sobresaliente");
}
Otro ejemplo del tema: calcular el valor absoluto con if (x < 0) x = -x;.

switch

La expresión puede ser int, byte, short, char o String. default es opcional.

switch clásico

switch (dia) {
    case 1:  System.out.println("Lunes");   break;
    case 2:  System.out.println("Martes");  break;
    default: System.out.println("Otro día");
}
Sin break hay fall-through: se siguen ejecutando los case siguientes.

El fall-through sirve para agrupar cases:

switch (mes) {
    case 1: case 3: case 5: case 7: case 8: case 10: case 12:
        System.out.println("31 días"); break;
    case 2:
        System.out.println("28 días"); break;
    default:
        System.out.println("30 días");
}

switch moderno (con ->, sin break)

switch (mes) {
    case 1, 3, 5, 7, 8, 10, 12 -> System.out.println("31 días");
    case 2 -> System.out.println("28 días");
    default -> System.out.println("30 días");
}

while y do-while

while (precondición)

Comprueba la condición antes; puede ejecutarse 0 veces.

int i = 1;
while (i <= 3) {
    System.out.println(i);
    i++;
}
// cuerpo vacío: raíz cuadrada entera
while (++sqrt * sqrt != target) ;

do-while (poscondición)

Comprueba después; se ejecuta al menos una vez. Termina en ;.

int i = 1;
do {
    System.out.println(i);
    i++;
} while (i <= 10);
whiledo-while
CondiciónAl principioAl final
Mínimo de ejecuciones01
Punto y coma finalNoSí

for

for (inicialización; condición; incremento) {
    // cuerpo
}

for (int i = 1; i <= 5; i++) {
    System.out.println(i);
}

Secuencia de control: 1) inicialización (una vez) → 2) condición → 3) cuerpo → 4) incremento → vuelve a 2. Sale cuando la condición es false.

break y continue

  • break: sale del bucle (o del switch) inmediatamente.
  • continue: salta a la siguiente iteración.
for (int i = 1; i <= 10; i++) {
    if (i == 3) continue;  // se salta el 3
    if (i == 6) break;     // termina en el 6
    System.out.println(i); // 1 2 4 5
}

Funciones en Java (introducción)

static tipo nombre(parámetros) {
    ...
    return valor;
}
static int sumar(int a, int b) { return a + b; }

Ventajas: reutilizar código, evitar repeticiones, organizar el programa y dividir un problema en partes.

Ejercicios propuestos: esPar, calcularAreaTriangulo, mostrarTabla, mayorDeTres. (Ver más en UT 3.)
Ver solución en Java
public class Propuestos {
    static boolean esPar(int n) {
        return n % 2 == 0;
    }

    static double calcularAreaTriangulo(double base, double altura) {
        return base * altura / 2;
    }

    static void mostrarTabla(int n) {
        for (int i = 1; i <= 10; i++) {
            System.out.println(n + " x " + i + " = " + (n * i));
        }
    }

    static int mayorDeTres(int a, int b, int c) {
        int mayor = a;
        if (b > mayor) {
            mayor = b;
        }
        if (c > mayor) {
            mayor = c;
        }
        return mayor;
    }

    public static void main(String[] args) {
        System.out.println(esPar(4));
        System.out.println(calcularAreaTriangulo(6, 3));
        mostrarTabla(2);
        System.out.println(mayorDeTres(4, 9, 2));
    }
}

PSeInt: estructuras de control (guía UT 2)

Fuente: guia_pseint_2016-11-20.pdf

Si-Entonces

Si <condición> Entonces
    <instrucciones>
Sino
    <instrucciones>
FinSi

Entonces siempre aparece; Sino es opcional. La condición debe ser una expresión lógica (Verdadero/Falso).

Selección múltiple (Según)

Segun <variable> Hacer
    1: <instrucciones>
    2, 3: <instrucciones>
    De Otro Modo: <instrucciones>
FinSegun

Depende del valor de una variable numérica. Cada opción lleva uno o varios números separados por comas. De Otro Modo es opcional.

Mientras Hacer (while)

Mientras <condición> Hacer
    <instrucciones>
FinMientras

Evalúa antes; el cuerpo puede no ejecutarse nunca. Si la condición siempre es verdadera: ciclo infinito, así que el cuerpo debe modificar las variables de la condición.

Repetir Hasta Que (do-while)

Repetir
    <instrucciones>
Hasta Que <condición>

Evalúa al final: el cuerpo se ejecuta al menos una vez y se repite hasta que la condición sea verdadera. (Ojo: es lo contrario que el while de Java, que repite mientras es verdadera.)

Para (for)

Para <variable> <- <inicial> Hasta <final> Con Paso <paso> Hacer
    <instrucciones>
FinPara

Si se omite Con Paso, se incrementa de 1 en 1.

Observaciones

  • Comentarios con // (no vale /* */).
  • No puede haber instrucciones fuera del proceso (sí comentarios).
  • Las estructuras pueden anidarse, pero la interna debe empezar y acabar dentro de la externa.
  • Los tipos no se declaran, se infieren. Constantes de texto entre comillas "; decimales con punto; lógicas Verdadero y Falso.

Ejecución paso a paso y prueba de escritorio

PSeInt permite ejecutar línea a línea («Primer Paso» / «Avanzar un paso»), pausar, evaluar variables o expresiones («Evaluar…») y ver la Prueba de Escritorio: una tabla con el valor de las variables tras cada línea.

Ejemplos que incluye PSeInt

  • AdivinaNumero: adivinar un número aleatorio (azar(100)+1) en 10 intentos con Mientras … Y intentos>0.
  • Mayores: los dos mayores de una lista de N datos (usa Dimension datos[200] y Para).
  • Triángulo: comprueba si 3 lados forman un triángulo rectángulo (Pitágoras) y calcula el área.
  • OrdenaLista: ordena nombres alfabéticamente (selección del menor).
  • Promedio: acumulador + Para.
// Promedio
Proceso Promedio
    Escribir "Ingrese la cantidad de datos:";
    Leer n;
    acum <- 0;
    Para i <- 1 Hasta n Hacer
        Escribir "Ingrese el dato ", i, ":";
        Leer dato;
        acum <- acum + dato;
    FinPara
    prom <- acum / n;
    Escribir "El promedio es: ", prom;
FinProceso

Patrones de bucles: contador, acumulador, máximo/mínimo

  • Contador: total++; (suma 1 cada vez).
  • Acumulador: suma += valor;
  • Máximo/mínimo: inicializar con un valor extremo (max = -9999, min = 9999) o con el primer dato, y comparar en cada vuelta.
  • Lectura adelantada: leer antes del bucle y volver a leer al final del cuerpo.
  • Centinela: valor que solo sirve para terminar (0, 99…) y no entra en los cálculos.
  • Media con decimales: media = (double) suma / total; (si no, división entera).
int edad, total = 0, suma = 0;
edad = teclado.nextInt();            // lectura adelantada
while (edad != 0) {
    suma += edad;
    total++;
    edad = teclado.nextInt();
}
double media = (double) suma / total;

1. Estructura de un método

En Java las funciones se llaman métodos y se declaran dentro de una clase. Sirven para organizar, reutilizar y dividir un problema en tareas pequeñas.

public static int sumar(int a, int b) {
    return a + b;
}

2. Declarar y llamar

Declarar = escribir qué hace. Llamar = ejecutarlo.

public class Ejemplo {
    public static int sumar(int a, int b) { return a + b; }

    public static void main(String[] args) {
        int resultado = sumar(4, 6);
        System.out.println(resultado); // 10
    }
}
Parámetros = variables de la declaración (a, b). Argumentos = valores que se pasan al llamar (4, 6).

3. Tipos de método según parámetros y retorno

Sin parámetros y sin retorno (void)

public static void saludar() { System.out.println("¡Hola!"); }
saludar();

Con parámetros y sin retorno

public static void saludarPersona(String nombre) {
    System.out.println("Hola, " + nombre);
}
saludarPersona("Ana");

Sin parámetros y con retorno

public static int obtenerNumero() { return 10; }
int numero = obtenerNumero();

Con parámetros y con retorno

public static double calcularArea(double base, double altura) {
    return base * altura / 2;
}
double area = calcularArea(6, 4); // 12.0

4. Cómo funciona return

return termina el método en ese momento. El valor debe ser compatible con el tipo de retorno.

public static boolean esPar(int numero) {
    return numero % 2 == 0;
}

Un método con retorno debe devolver valor en todos los caminos:

public static String comprobarEdad(int edad) {
    if (edad >= 18) {
        return "Mayor de edad";
    }
    return "Menor de edad";
}

En un void se puede usar return; para salir antes:

public static void mostrarDivision(double a, double b) {
    if (b == 0) {
        System.out.println("No se puede dividir entre cero");
        return;
    }
    System.out.println(a / b);
}
Mostrar ≠ devolver: println escribe en pantalla; return entrega un resultado al código que llamó.

5. Métodos static y de instancia

Un método static se llama con el nombre de la clase:

public class Calculadora {
    public static int multiplicar(int a, int b) { return a * b; }
}
int resultado = Calculadora.multiplicar(3, 4);

Uno de instancia necesita un objeto:

public class Persona {
    public void saludar() { System.out.println("¡Hola!"); }
}
Persona persona = new Persona();
persona.saludar();

Desde main (que es static) necesitas un objeto para llamar a un método de instancia.

6. Sobrecarga de métodos

Varios métodos con el mismo nombre si cambia el número, el tipo o el orden de los tipos de los parámetros.

public static int sumar(int a, int b)           { return a + b; }
public static double sumar(double a, double b)  { return a + b; }
public static int sumar(int a, int b, int c)    { return a + b + c; }

sumar(2, 3);       // 5
sumar(2.5, 3.5);   // 6.0
sumar(2, 3, 4);    // 9
Cambiar solo el tipo de retorno no permite sobrecargar.

7. Ámbito de las variables

Parámetros y variables locales solo existen dentro de su método.

public static int duplicar(int numero) {
    int resultado = numero * 2;
    return resultado;
}
// fuera no existen numero ni resultado
int doble = duplicar(5);   // recoge el valor devuelto

8. Paso de argumentos por valor

Java siempre pasa por valor: el método recibe una copia.

public static void cambiar(int numero) { numero = 100; }
int valor = 5;
cambiar(valor);
System.out.println(valor);   // 5

Con objetos y arrays se copia la referencia, así que el método sí puede modificar el contenido:

public static void cambiarPrimero(int[] numeros) { numeros[0] = 100; }
int[] datos = {1, 2, 3};
cambiarPrimero(datos);
System.out.println(datos[0]);   // 100

Pero asignar un objeto nuevo al parámetro no cambia la variable del llamador.

9. Recursividad

Un método es recursivo si se llama a sí mismo. Necesita un caso base que detenga las llamadas.

// válido para n entre 0 y 12
public static int factorial(int n) {
    if (n < 0 || n > 12) {
        throw new IllegalArgumentException("n debe estar entre 0 y 12");
    }
    if (n == 0) {
        return 1;               // caso base
    }
    return n * factorial(n - 1);
}
factorial(4);   // 4 × 3 × 2 × 1 = 24

El límite 12 evita que el resultado supere la capacidad de int.

10. Errores frecuentes

  • Olvidar devolver valor en un método que no es void.
  • Confundir imprimir con devolver.
  • Pasar argumentos con tipos o cantidad incorrectos.
  • Llamar a un método de instancia desde main sin crear un objeto.
  • Declarar un método dentro de otro.
  • Creer que cambiar un parámetro primitivo modifica la variable original.

11. Clases, objetos y métodos

Una clase describe un tipo y las operaciones que se pueden hacer con él. Un objeto es un ejemplar concreto de esa clase. Cada objeto tiene un estado (sus datos), un comportamiento (lo que sabe hacer) y una identidad propia: una variable de tipo objeto guarda una referencia a él.

import java.awt.Point;

Point punto = new Point(2, 3);
punto.setLocation(4, 5);   // cambia la posición a (4, 5)

El import va al principio del archivo y permite usar el nombre corto Point.

12. Paquetes y import

Un paquete agrupa clases relacionadas. En java.awt.Point, java.awt es el paquete y Point la clase.

  • java.lang: clases fundamentales como Math, Integer o String. No necesitan import.
  • java.util: utilidades, como Scanner.
  • java.io: entrada y salida de datos.
  • java.time: fechas y horas, como LocalDate.

Un import no instala nada: solo permite usar el nombre corto. La clase ya forma parte de Java.

13. Leer la documentación de la API

La documentación de Java indica, para cada clase, sus constructores (cómo se crea un objeto), sus métodos (qué parámetros piden y qué devuelven) y las excepciones que pueden lanzar. Busca la clase por su nombre en la documentación de la versión de Java que uses.

  • Si el método es static, se llama con el nombre de la clase: Math.sqrt(25).
  • Si necesitas un objeto, usa new con un constructor público, o un método estático que te lo devuelva.
  • Los métodos de instancia se llaman con la referencia del objeto: punto.getX().
Point punto = new Point(2, 3);
double x = punto.getX();   // 2.0
Point origen = new Point(); // (0, 0)

Declarar Point punto; solo reserva la variable. Hasta que no le asignes un objeto con new (u otro método que lo devuelva), no puedes usarla.

19. Programación modular

Dividir un programa en partes pequeñas, llamadas módulos, que hacen una tarea concreta. En Java, la forma más sencilla son los métodos (también llamados funciones).

Ventajas

  • Organización: un programa complejo se divide en partes sencillas.
  • Reutilización: un método se usa varias veces sin repetir código.
  • Legibilidad y mantenimiento: cambias una parte sin tocar todo el programa (si cambia el IVA, solo editas calcularIVA()).
  • Depuración: es más fácil localizar el error.
  • Trabajo en equipo: cada persona programa un módulo.

Con valor devuelto: se puede usar dentro de una expresión. void: se llama como instrucción independiente. Una buena práctica es que los métodos devuelvan resultados y que main se encargue de mostrarlos.

20. Métodos que llaman a otros métodos y descomposición de un programa

Un método no tiene que llamarse solo desde main: también puede llamar a otros.

public class Operaciones {
    public static void main(String[] args) {
        int resultado = calcularDobleSuma(3, 4);
        System.out.println(resultado);        // 14
    }

    public static int sumar(int a, int b) {
        return a + b;
    }

    public static int calcularDobleSuma(int a, int b) {
        int suma = sumar(a, b);               // llama a otro método
        return suma * 2;
    }
}

Orden: main llama a calcularDobleSuma(3, 4) → llama a sumar(3, 4) → devuelve 7 → se multiplica por 2 → devuelve 14 → main lo muestra.

Reutilización: un método se define una vez y se usa varias veces (calcularCuadrado(3), calcularCuadrado(5)...). Un método sin parámetros también es útil, por ejemplo mostrarMenu().

Cómo dividir un problema en métodos

  1. Analizar: datos de entrada y resultados.
  2. Dividir en operaciones principales.
  3. Diseñar cada método: qué recibe y qué devuelve.
  4. Programar cada método.
  5. Programa principal: pide los datos, llama a los métodos y muestra resultados.
  6. Probar cada método y el programa completo.

Buenas prácticas

  • Una tarea por método.
  • Nombres descriptivos (calcularMedia(), mostrarMenu(), no metodo1()).
  • No repetir código: si algo se usa varias veces, método.
  • Pasar por parámetros lo que necesita y devolver resultados con return.
  • main solo coordina.
  • Cohesión alta: las instrucciones de un método son de una misma tarea. Acoplamiento bajo: un módulo depende poco de los detalles internos de otros.

Detalles de la guía que suelen caer en test

  • x++ produce el valor anterior y luego incrementa; ++x incrementa y produce el valor nuevo.
  • && y || usan cortocircuito: si el primer operando ya decide el resultado, no evalúan el segundo.
  • El casting a int trunca (hacia cero), no redondea: (int) 2.9 es 2 y (int) -2.9 es -2.
  • Una variable local no tiene valor por defecto (error si la lees sin inicializar). Los campos de una clase y los elementos de un array sí: 0, false o null.
  • Una variable final se asigna una sola vez (puede ser después de declararla). Reasignarla es error de compilación.
  • true, false y null son literales, no palabras reservadas, pero tampoco sirven de nombre. const y goto están reservadas aunque no se usan. _ solo no es un identificador válido.
  • Desbordamiento de enteros: resultado circular, sin excepción.
  • Ensanchamiento automático: byte → short → int → long → float → double y char → int. int a char necesita casting. boolean no se convierte a números.
  • float y double tienen precisión limitada (existen NaN e infinitos).
  • Sin llaves, un else se asocia al if más cercano que aún no tenga else.
  • switch: el selector es byte, short, char, int o String (no long, float, double ni boolean); los case no se repiten; default es opcional y no tiene que ir al final; sin break continúa por los casos siguientes. La forma con flecha -> no necesita break (Java 14 o superior).
  • while (condicion); con punto y coma: el ; es el cuerpo vacío del bucle.
  • for: las tres partes son opcionales, pero se conservan los dos ;. for (;;) es infinito. Una variable declarada en la cabecera solo existe dentro del for.
  • break sale solo del bucle (o switch) más interno. continue en un for ejecuta la actualización y luego comprueba la condición.
  • Si ambos operandos de / son enteros, se descarta la parte decimal.
