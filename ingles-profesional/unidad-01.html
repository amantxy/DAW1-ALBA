Reading: Inside the boxLectura y comprensión

Every computer, from a small laptop to a powerful server, follows the same basic idea: it receives data, processes it, stores it and shows a result. Input devices such as the keyboard and the mouse send data to the computer. Output devices such as the screen and the printer show the result.

The motherboard is the main circuit board. It connects all the components and lets them communicate. The CPU is often called the brain of the computer because it carries out the instructions of each program. While a program is running, the CPU uses RAM to keep data that it needs quickly. RAM is fast, but it loses its contents when the computer switches off. For this reason, files stay on a hard drive or an SSD, which keeps data without power.

Grammar: Present simple and present continuousGramática explicada

El present simple expresa hábitos, hechos y cómo funciona algo. El present continuous expresa lo que ocurre ahora o en este periodo.

FormaCómo se usaEjemplo
Present simpleI/you/we/they + verbo; he/she/it + verbo + -sThe CPU processes instructions.
Negativadon't / doesn't + verboThis laptop doesn't have a webcam.
PreguntaDo / Does + sujeto + verbo?Does it have an SSD?
Present continuousam / is / are + verbo-ingThe system is installing an update.
Negativaam / is / are + not + verbo-ingThe printer isn't working.
PreguntaAm / Is / Are + sujeto + verbo-ing?Are you using this computer?
Fíjate en esto
  • Con present simple suelen ir always, usually, often, sometimes y never.
  • Con present continuous suelen ir now, at the moment, today y this week.
  • Verbos como know, need, want y have (poseer) casi nunca van en continuo: «I need more RAM», no «I am needing».
