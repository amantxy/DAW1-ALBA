Reading: From Java to the WebLectura y comprensión

A programming language lets people give instructions to a computer. Java appeared in 1995 and is still common in business software and server applications. A Java compiler translates source code into bytecode, and the Java Virtual Machine runs that bytecode. This is why the same program can run on different operating systems.

Web programmers often work in two areas. Front-end developers build what users see, using HTML, CSS and JavaScript. Back-end developers work on the server and on databases, with languages such as Java or Python. Whatever the language, developers spend a lot of time testing and debugging. A small bug can stop a whole program, so clear code and good habits are essential.

Grammar: Giving instructionsGramática explicada

Para dar instrucciones se usa el imperativo, junto con conectores que marcan el orden.

FormaCómo se usaEjemplo
Imperativoverbo sin sujetoOpen the file.
Imperativo negativodon't + verboDon't delete this line.
Ordenfirst, then, next, after that, finallyFirst, declare the variable. Then, assign a value.
Condiciónif + presente, imperativoIf you see an error, check the syntax.
Finalidadto + verboPress F6 to run the program.
Con precauciónmake sure (that) / remember toMake sure that you save the file.
Fíjate en esto
  • El imperativo inglés no lleva «you» delante en instrucciones normales.
  • Para expresar finalidad se usa to, no for: «to run it», no «for run it».
  • Palabras reservadas de Java como int, for o if van siempre en minúsculas.

Modelo

How to create a Java program in NetBeans
First, open NetBeans and create a new Java project. Then, give the project a clear name. Next, write this line inside the main method: System.out.println("Hello, world"); After that, save the file. Finally, press F6 to run the program and check the output.
Remember: don't forget the semicolon at the end of the line.

Se guarda solo. No se corrige automáticamente.
