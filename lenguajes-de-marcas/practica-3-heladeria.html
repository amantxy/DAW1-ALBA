Práctica · Heladería La Nube

Práctica del Tema 3 (CSS). Vas a crear una web con cabecera, contenido principal y pie. Cada parte tiene un fondo distinto: uno se repite, otro se expande y otro se coloca en un sitio concreto. Abre cada desplegable para ver cómo se hace.

Cómo se hace, paso a paso

Antes de empezar: carpetas y rutas

Tu web necesita esta estructura: index.html en la raíz, la carpeta css/ con estilos.css y la carpeta img/ con las imágenes.

La ruta de una imagen se escribe desde el archivo donde está. En el HTML, img/logo.svg. En el CSS, que está dentro de css/, hay que subir una carpeta: ../img/cucuruchos.svg.

<link rel="stylesheet" href="css/estilos.css">
Paso 1 · HTML de la cabecera

La cabecera (<header>) agrupa el logo, el título y el menú. El logo lleva width y height de 64 px y un alt para lectores de pantalla.

Los enlaces href="#sabores" llevan a la parte de la página cuyo id es sabores. El # indica que es un enlace interno.

<header>
  <img src="img/logo.svg" width="64" height="64" alt="Logo de La Nube">
  <h1>Heladería La Nube</h1>
  <nav>
    <a href="#sabores">Sabores</a>
    <a href="#contacto">Dónde estamos</a>
  </nav>
</header>
Paso 2 · HTML del contenido principal

El contenido va en <main id="sabores">. Una lista desordenada (ul) con un li por sabor.

Para marcar solo un trozo de una línea se usa un elemento en línea, como <span>. Así el pistacho o el importe se pueden seleccionar sin tocar el resto del texto. Por eso el importe va en un span y no en un bloque.

<main id="sabores">
  ...
  <li><span class="nuevo">Pistacho salado</span></li>
  ...
  <div class="precio">Una bola: <span class="importe">2,50 €</span></div>
</main>
Paso 3 · HTML del pie

El pie (<footer id="contacto">) tiene tres líneas, cada una en su contenedor. Un enlace externo empieza por https://, a diferencia de los internos, que empiezan por #.

<footer id="contacto">
  <p>Calle de los Barquillos, 7</p>
  <p class="horario">Abrimos todos los días de 12:00 a 22:00.</p>
  <p><a href="https://example.com/mapa">Ver en el mapa</a></p>
</footer>
Paso 4 · Colores de la página

Una regla con un selector (body) afecta a toda la página. background-color pone el color de fondo y color el del texto.

body {
  background-color: #fdeef3;
  color: #4a2c2a;
}
Paso 5 · Títulos en granate

Puedes aplicar una sola regla a varios selectores separándolos con comas. Así h1 y h2 comparten el mismo color.

h1, h2 {
  color: #8c2f4b;
}
Paso 6 · Fondo que se repite (cabecera)

background-image pone una imagen de fondo. Por defecto se repite en horizontal y en vertical, así que repeat es el valor normal.

El color de fondo sirve de respaldo si la imagen no carga.

header {
  background-color: #f7c6d0;
  background-image: url("../img/cucuruchos.svg");
  background-repeat: repeat;
}
Paso 7 · Fondo que se expande (contenido principal)

La propiedad background (abreviada) reúne color, imagen, repetición y posición en una línea.

no-repeat evita que la imagen se repita. center / cover la centra y, con cover, la escala hasta cubrir toda la caja. Lo que sobra se recorta. La barra separa la posición del tamaño.

#sabores {
  background: #7cc6bf url("../img/helados.svg") no-repeat center / cover;
}
Paso 8 · Franja blanca sin apagar el texto

Si pones opacity en un elemento, se vuelve transparente todo, incluido el texto. Para que solo el fondo sea transparente, escribe el color con rgba(): rojo, verde, azul y, al final, la opacidad (de 0 a 1). Aquí 0.75 es el 75 %.

El padding deja aire alrededor del texto dentro de la franja.

header h1, #sabores h2 {
  background-color: rgba(255, 255, 255, 0.75);
  padding: 0.2em 0.5em;
}
Paso 9 · Sabor nuevo y precios

Una clase (.nombre) sirve para escoger elementos concretos. Se escribe el punto delante del nombre, y en el HTML se pone class="nombre".

.nuevo, .importe {
  color: #6e1f38;
}
Paso 10 · Fondo colocado (pie)

background-position coloca la imagen en un sitio concreto: right center es a la derecha y centrada en vertical.

no-repeat hace que aparezca una sola vez.

footer {
  background-color: #3d2c3e;
  color: #f6e7d8;
  background-image: url("../img/nube.svg");
  background-repeat: no-repeat;
  background-position: right center;
}
Paso 11 · Horario apagado

opacity de 0 a 1 apaga el elemento completo. Aquí se usa sobre el texto, y está bien porque no hay fondo que deba quedarse opaco.

.horario {
  opacity: 0.7;
}
Paso 12 · Enlaces según su destino

Los selectores de atributo buscan elementos por un atributo. a[href^="#"] elige los enlaces cuyo href empieza por # (internos). a[href^="https"] elige los que empiezan por https (externos).

Así no hace falta ninguna clase en el HTML.

header nav a[href^="#"] {
  color: #6e1f38;
}
footer a[href^="https"] {
  color: #f7c6d0;
}
