1. Las etiquetas

Una etiqueta (tag) es una marca que el navegador reconoce y que indica qué es un fragmento de contenido. Se escribe entre < y >: <p>, <img>, <a>. La mayoría van por parejas: apertura y cierre (con / delante del nombre), y entre ambas el contenido.

<p>Este es el contenido del párrafo.</p>
  • Apertura + contenido + cierre = elemento.
  • Las etiquetas vacías (void elements) no tienen contenido ni cierre: <br>, <hr>, <img>, <input>.
  • HTML no distingue mayúsculas en los nombres, pero se escriben en minúsculas.
Actividad 1 · Copia <strong>Aviso importante</strong>, señala apertura, cierre y contenido, y escribe una línea parecida con <em>.

Esqueleto de un HTML5

<!DOCTYPE html>
<html lang="es">
<head>
  <meta charset="UTF-8">
  <title>Título de la página</title>
</head>
<body>
  <!-- Aquí va el contenido visible -->
</body>
</html>
  • <!DOCTYPE html>: no es una etiqueta, es una declaración: «interpreta esto como HTML5». Sin ella, algunos navegadores activan el *quirks mode*. Va en la primera línea.
  • <html lang="es">: etiqueta raíz. lang indica el idioma: lo usan lectores de pantalla (pronunciación), traductores y buscadores.
  • <meta charset="UTF-8">: codificación de caracteres (la tabla que convierte bytes en letras). UTF-8 representa casi cualquier carácter, incluidas ñ, tildes y emojis. Va la primera dentro del head porque el navegador necesita saber cómo leer el resto.
  • <head>: cabecera; no se ve; contiene metadatos, título y enlaces a CSS.
  • <title>: texto de la pestaña y de los resultados de buscadores.
  • <body>: todo el contenido visible.

2. Elementos: cabeceras y párrafos

Un elemento es etiqueta de apertura + contenido + etiqueta de cierre (o la etiqueta sola si es vacía). <p>Hola</p> es un elemento; <p> sola es solo la etiqueta.

Los elementos pueden anidarse y deben cerrarse en orden inverso al de apertura (como muñecas rusas).

<!-- Correcto: strong se cierra antes que p -->
<p>Hola <strong>mundo</strong></p>

<!-- Incorrecto: los cierres están cruzados -->
<p>Hola <strong>mundo</p></strong>
Actividad 3 · Párrafo con una palabra en negrita (strong) que además va en cursiva (em), cerrando en el orden correcto.
  • <h1> a <h6>: encabezados, de mayor a menor importancia. Cada página debería tener un único h1.
  • <p>: párrafo; el navegador añade espacio antes y después.
  • Saltos de línea del código: HTML colapsa espacios y saltos de línea del código fuente en un único espacio; pulsar Intro dentro de un párrafo no mueve nada.
  • Elementos de bloque (p, h1) añaden espacio al terminar; los en línea (strong, a) no.
  • <br>: obliga a bajar de línea (no crea párrafo). Vacía.
  • <hr>: línea horizontal que separa temas. Vacía.
<h1>Mi página personal</h1>
<h2>Sobre mí</h2>
<p>Estudio Lenguajes de Marcas.<br>
Este es mi primer documento HTML.</p>
<hr>
<h2>Contacto</h2>

3. Atributos

Un atributo añade información extra a una etiqueta. Va siempre dentro de la etiqueta de apertura, con la forma nombre="valor"; puede haber varios separados por espacios, y el valor va entre comillas.

  • Algunas etiquetas los necesitan para tener sentido: <a> sin href no lleva a ningún sitio; <img> sin src no tiene qué mostrar.
  • Algunos son de una etiqueta (href en <a>) y otros globales: id, class, title, lang, style.
<a href="https://www.w3schools.com">Ir a W3Schools</a>
<img src="foto.jpg" alt="Foto de perfil">

5. Comentarios

<!-- ... -->: el navegador lo ignora por completo. Sirve para dejar notas, explicar el código o desactivar una línea sin borrarla.

<!-- Esto es un comentario, no se ve en la página -->
<p>Este párrafo sí se ve.</p>
<!-- <p>Este párrafo está desactivado</p> -->
  • Los comentarios no pueden anidarse y no deben ocultar información sensible: cualquiera ve el código fuente.

6. Colores

El aspecto visual no se define con etiquetas HTML sino con CSS (Unidad 3). Tres formas de indicar un color:

  • Nombre: unos 140 nombres en inglés (red, navy, tomato, lightgray). Legible, pero poco preciso.
  • RGB: rgb(rojo, verde, azul), cada componente de 0 a 255. rgb(255, 0, 0) es rojo puro; rgb(0, 0, 0), negro; rgb(255, 255, 255), blanco.
  • Hexadecimal: #RRGGBB, los mismos componentes en base 16 (00 a FF). #FF0000 es el mismo rojo; #1F4E79 es el azul marino de los apuntes.
<p style="color: tomato;">Color con nombre.</p>
<p style="color: rgb(31, 78, 121);">Color con RGB.</p>
<p style="color: #1F4E79;">Color hexadecimal.</p>

7. Cómo enlazar CSS con HTML

Tres formas: inline, internal y external.

  • style="..." (inline): atributo en cualquier etiqueta. Rápido para probar, pero mezcla contenido y estilo.
  • <style> (internal): en el head, CSS dentro del propio documento.
  • <link rel="stylesheet" href="..."> (external): en el head, enlaza un .css. La recomendada: separa contenido y presentación y el archivo se reutiliza en varias páginas.
<head>
  <link rel="stylesheet" href="estilos.css">   <!-- external -->
  <style> h1 { color: navy; } </style>          <!-- internal -->
</head>
<body>
  <p style="color: red;">Texto rojo.</p>        <!-- inline -->
</body>

8. El atributo class

class asigna a un elemento uno o varios nombres de grupo, para aplicarles el mismo estilo con CSS o seleccionarlos con JavaScript. Se puede repetir en tantos elementos como se quiera, y un elemento puede tener varias clases separadas por espacios.

<p class="aviso">Pertenece a la clase "aviso".</p>
<p class="aviso urgente">Pertenece a dos clases.</p>
<h2 class="aviso">También un encabezado.</h2>

En la Unidad 3 será uno de los tres «ganchos» de CSS (junto con el elemento y el id).

Actividad 10 · Dale la misma class="destacado" a varios párrafos de distintas partes de la página.

9. El atributo id

id identifica a un elemento de forma única en toda la página: no debe repetirse. Sin espacios ni tildes.

<h2 id="contacto">Contacto</h2>
<p>Se puede enlazar con href="#contacto".</p>
  • class agrupa (varios elementos, varias veces); id identifica (un único elemento, una sola vez).

10. Enlaces

<a href="..."> crea un hipervínculo; href indica el destino.

  • target="_blank": abre en pestaña nueva.
  • href="mailto:correo@dominio.com": abre el gestor de correo.
  • href="tel:+34600000000": en el móvil abre la app de teléfono.
  • href="#id": lleva a un elemento con ese id de la misma página (ancla).
  • download: descarga el archivo en vez de navegar.
<a href="https://www.w3schools.com" target="_blank">Ir a W3Schools</a>
<a href="mailto:ejemplo@instituto.es">Escríbeme</a>
<a href="tel:+34600000000">Llámame</a>
<a href="#contacto">Ir a contacto</a>
<a href="apuntes.pdf" download>Descargar apuntes</a>

11. Rutas relativas y absolutas

  • Ruta absoluta: dirección completa empezando por http:// o https://, normalmente a otra web. Deja de servir si esa web cambia.
  • Ruta relativa: posición del archivo respecto a la página actual, sin dominio. Recomendada dentro de un proyecto: sigue funcionando si se mueve todo.
RutaSignificado
foto.jpgMisma carpeta que la página
imagenes/foto.jpgSubcarpeta «imagenes» de la carpeta actual
../foto.jpgCarpeta anterior (un nivel arriba)
/imagenes/foto.jpgSubcarpeta «imagenes» de la raíz del sitio

12. Imágenes

<img src="..." alt="..."> inserta una imagen. Es vacía. src es la ruta; alt es el texto alternativo, obligatorio por accesibilidad (lo leen los lectores de pantalla y se muestra si la imagen no carga).

Lo habitual: ruta relativa para imágenes propias y URL completa solo si vive en otro servidor.

width y height (en píxeles) cambian el tamaño y evitan que la página «salte» al cargar. Si solo se indica uno, el navegador calcula el otro y mantiene la proporción; si se indican ambos sin respetarla, la imagen se deforma. Centrar con <center> o align está obsoleto: se hace con CSS.

<img src="imagenes/perfil.jpg" alt="Foto de perfil" width="200" height="200">
<img src="imagenes/perfil.jpg" alt="Foto de perfil" width="200">
Actividad 14 · Imagen con ruta relativa y alt descriptivo; prueba a indicar solo width.

Mapa de imagen: map y area

usemap="#nombre" en la imagen apunta al name del <map>; dentro, cada <area shape coords href> es una región pulsable (rect, circle o poly). Las coordenadas son píxeles sobre el tamaño real: si la imagen se redimensiona, las zonas dejan de coincidir.

<img src="instituto.jpg" alt="Plano" usemap="#plano">
<map name="plano">
  <area shape="rect" coords="0,0,150,100" href="biblioteca.html" alt="Biblioteca">
  <area shape="rect" coords="150,0,300,100" href="cafeteria.html" alt="Cafetería">
</map>

Imágenes responsivas: picture

<picture> agrupa varias imágenes y el navegador elige según pantalla o formato. Lleva uno o varios <source media srcset> y, siempre al final, un <img> de reserva.

<picture>
  <source media="(min-width: 650px)" srcset="imagenes/paisaje-grande.jpg">
  <source media="(min-width: 465px)" srcset="imagenes/paisaje-mediano.jpg">
  <img src="imagenes/paisaje-pequeno.jpg" alt="Paisaje de montaña">
</picture>

13. Tablas

<table> organiza datos en filas y columnas. Partes:

  • <tr>: fila.
  • <th>: celda de encabezado (negrita y centrada por defecto).
  • <td>: celda de datos.
  • <caption>: título de la tabla; va justo después de <table>.
  • border="1": borde sencillo (atributo antiguo; hoy se hace con CSS).
  • colspan="n" / rowspan="n": la celda ocupa n columnas / n filas.
  • Tamaño y padding (width, height, padding): hoy con CSS; cellpadding solo para reconocerlo en código antiguo.
<table border="1">
  <caption>Horario de clase</caption>
  <tr><th>Hora</th><th>Lunes</th><th>Martes</th></tr>
  <tr><td>9:00</td><td colspan="2">Lenguajes de Marcas</td></tr>
  <tr><td rowspan="2">10:00</td><td>Programación</td><td>Inglés técnico</td></tr>
  <tr><td>Bases de Datos</td><td>Sistemas Operativos</td></tr>
</table>

Dato histórico: antes se usaban tablas para maquetar la página entera; hoy es mala práctica: una tabla es solo para datos tabulares y para maquetar están header, nav, main… con CSS.

14. Listas

  • <ol> / <li>: lista ordenada (numerada), cuando el orden importa (pasos de una receta).
  • <ul> / <li>: lista desordenada (viñetas), cuando no importa (ingredientes, aficiones).
  • <dl> / <dt> / <dd>: lista de definiciones: dt es el término y dd su definición. No es una lista de elementos sueltos, sino de pares término-definición (glosarios, preguntas y respuestas).
<ol><li>Calienta el agua</li><li>Añade el café</li></ol>
<ul><li>Café molido</li><li>Agua</li></ul>
<dl>
  <dt>HTML</dt><dd>Lenguaje de marcas para construir páginas web.</dd>
  <dt>Etiqueta</dt><dd>Marca que indica qué es cada parte del contenido.</dd>
</dl>

Las listas se combinan con otros elementos: un enlace dentro de cada li forma un menú de navegación.

15. Contenedores genéricos: div y span

  • <div>: contenedor genérico a nivel de bloque, sin significado propio; solo agrupa (para CSS o JavaScript).
  • <span>: selecciona una parte pequeña de texto para aplicarle estilo o identificarla, sin crear un párrafo nuevo.
<div>
  <h2>Tarjeta de producto</h2>
  <p>Precio: 19,99€</p>
</div>
<p>La respuesta es <span style="color: red;">importante</span>.</p>

16. Elementos de bloque y en línea

  • Bloque (block): empieza en una línea nueva y ocupa todo el ancho disponible. Ejemplos: p, div, h1-h6, ul, li, table, header, section.
  • En línea (inline): no empieza línea nueva, ocupa solo el ancho de su contenido y fluye con el texto. Ejemplos: span, a, strong, em, img, b, i.

A un elemento en línea no se le pueden aplicar width ni height. Se puede cambiar con la propiedad CSS display (Unidad 3).

17. Formularios

Un formulario es la parte de la página donde el usuario introduce información: un nombre, un mensaje, una búsqueda, los datos de una compra.

<form> agrupa todos los campos para que el navegador los trate como un conjunto y los envíe de una vez. Por sí solo no muestra nada: es un contenedor invisible cuyos atributos definen qué pasa al enviar.

<form>
  <!-- aquí dentro van los campos: input, select, textarea... -->
</form>
Actividad 30 · Crea una página con un form vacío.

18. action y method

  • action: la URL a la que se envían los datos. Vacío (action=""), se envía a la propia página.
  • method: cómo se envían. get los añade visibles en la URL (?nombre=Ana&edad=16): búsquedas. post los envía ocultos en el cuerpo: obligatorio para datos sensibles (contraseñas) o formularios largos.
<form action="/enviar" method="post">
  <!-- campos -->
</form>

Truco para probar: usa https://httpbingo.org/post como action: acepta formularios por POST y devuelve todos los campos tal cual los recibió.

Actividad 31 · Explica qué cambia entre enviar con get y con post (barra de direcciones) y prueba un formulario tuyo con httpbingo.

19. target y novalidate

  • target: dónde se carga la respuesta; _blank abre pestaña nueva.
  • novalidate: desactiva la validación automática del navegador en todo el formulario (avisos de «rellena este campo»). Se usa poco.
<form action="/enviar" method="post" target="_blank" novalidate>
</form>

20. label

<label> asocia un texto descriptivo a un campo. Mejora la accesibilidad y la comodidad: al hacer clic en la etiqueta, el foco pasa al campo (en checkbox o radio, lo marca).

  • for: el id del campo; for e id deben coincidir exactamente.
  • form: asocia el label a un formulario por su id cuando no está dentro del form.
<label for="nombre">Nombre:</label>
<input type="text" id="nombre" name="nombre">

21. Tipos de input

<input type="..."> es una única etiqueta cuyo comportamiento cambia según type.

Error típico: <input ...>Nombre</input> no funciona. input es un elemento vacío, sin cierre: el navegador ignora </input> y «Nombre» queda como texto suelto sin relación con el campo. Para asociar un texto, usa <label>.

Texto

  • text: una línea libre; es el tipo por defecto. Atributos: size, maxlength, placeholder, pattern, value, required.
  • password: muestra cada carácter como punto o asterisco. Mismos atributos más autocomplete (new-password o current-password). minlength fija la longitud mínima.
  • email: comprueba que tenga forma de correo (algo@algo.algo). Atributo multiple: varios correos separados por comas.
  • tel: abre teclado numérico en móvil, pero no valida ningún formato por defecto; para forzarlo, pattern (por ejemplo [0-9]{9} para nueve dígitos).
  • url: valida que tenga forma de dirección web (empieza por http:// o https://).
  • search: como text, semánticamente para cajas de búsqueda (en algunos navegadores muestra una cruz para vaciarlo).
<input type="text" id="nombre" name="nombre" size="20" maxlength="30" placeholder="Tu nombre">
<input type="password" id="clave" name="clave" minlength="8" required>
<input type="email" id="email" name="email" required>
<input type="tel" id="telefono" name="telefono" pattern="[0-9]{9}">
<input type="url" id="web" name="web" placeholder="https://...">
<input type="search" id="buscar" name="q">

Números

  • number: solo números, con flechas. Atributos min, max, step.
  • range: deslizador (por defecto de 0 a 100). Atributos min, max, step.
<input type="number" id="edad" name="edad" min="14" max="99" step="1">
<input type="range" id="volumen" name="volumen" min="0" max="100" step="10" value="50">

Fechas y horas

TipoQué selecciona
dateUn día completo
timeUna hora (horas y minutos)

weekUna semana y un año

Atributos: min, max y step (p. ej. step="1800" en un time para intervalos de media hora).

Otros

  • color: selector de color nativo; value es siempre un hexadecimal (#1F4E79).
  • checkbox: casilla; varias pueden marcarse a la vez, son independientes. checked la marca de inicio; value es lo que se envía (si falta, on).
  • radio: solo se puede marcar uno entre los que comparten el mismo name. value es imprescindible.
  • file: botón «Examinar». accept limita tipos (image/*, application/pdf); multiple permite varios archivos.
  • hidden: no se ve, pero se envía; para datos que la página ya conoce (el id de un producto).

<input type="checkbox" id="acepto" name="acepto" required>
<input type="radio" id="manana" name="turno" value="manana" checked>
<input type="radio" id="tarde" name="turno" value="tarde">
<input type="file" id="foto" name="foto" accept="image/*">
<input type="hidden" name="id_producto" value="4821">

El menú desplegable: select

<select> / <option> no es un input: crea un desplegable con opciones predefinidas, y el usuario solo elige entre ellas. value puede diferir del texto.

  • selected (en option): elegido por defecto.
  • multiple (en select): varias opciones a la vez.
  • <optgroup label="...">: agrupa opciones bajo un subtítulo.
<select id="asunto" name="asunto">
  <optgroup label="Académico">
    <option value="notas">Notas</option>
    <option value="matricula" selected>Matrícula</option>
  </optgroup>
  <optgroup label="Otros">
    <option value="otro">Otro</option>
  </optgroup>
</select>
Actividades 34-48 · Un campo de ciudad con placeholder y maxlength; contraseña obligatoria de mínimo 8; correo obligatorio; teléfono de nueve dígitos con pattern; url; búsqueda; number (1 a 10, valor 1); range del 1 al 10; date y time; color; select con dos optgroup y un selected; tres checkbox; tres radio con el mismo name; file solo para PDF; y un hidden llamado «origen».

22. Botones en el formulario

Los botones no recogen datos: solo disparan una acción. Un input de estos tipos solo muestra texto plano (su value).

  • type="submit": envía el formulario.
  • type="reset": borra los campos y los deja en su valor inicial.
  • type="button": no hace nada por sí solo; necesita JavaScript (Unidad 4).
  • type="image": botón de envío con imagen (usa src, alt, width, height).
<input type="submit" value="Enviar">
<input type="reset" value="Borrar todo">
<input type="image" src="boton-enviar.png" alt="Enviar formulario" width="120">

formaction, formmethod y formtarget

<button type="submit"> e <input type="submit"> aceptan formaction: ESE botón envía el formulario a una URL distinta de la del action. formmethod y formtarget hacen lo mismo con method y target.

<form action="/publicar" method="post">
  <textarea name="texto"></textarea>
  <button type="submit">Publicar</button>
  <button type="submit" formaction="/borrador">Guardar como borrador</button>
  <button type="reset">Borrar todo</button>
</form>
Actividades 49-51 · Botones «Confirmar» (submit) y «Cancelar» (reset); tres botones con un formaction distinto; y el formulario de inscripción a un evento (POST a httpbingo con nombre, contraseña, correo obligatorio, teléfono con pattern, edad, fecha, select con optgroup, dos checkbox, tres radio, hidden y tres botones: submit, reset y button con formaction).

23. datalist

<datalist> define sugerencias para un input de texto. A diferencia de select, el usuario puede escribir libremente. El input se conecta con el atributo list, que debe coincidir con el id del datalist (el mismo emparejamiento por id que label/for).

<input type="text" id="navegador" name="navegador" list="navegadores">
<datalist id="navegadores">
  <option value="Chrome">
  <option value="Firefox">
  <option value="Edge">
</datalist>
Actividad 52 · Campo «Lenguaje de programación favorito» con un datalist de al menos cinco sugerencias.

24. textarea

<textarea>: texto de varias líneas. Su contenido inicial va entre la apertura y el cierre, no en value. rows y cols: alto (líneas) y ancho (caracteres); maxlength y placeholder funcionan como en input.

<textarea id="mensaje" name="mensaje" rows="4" cols="40" placeholder="Escribe aquí..."></textarea>
Actividad 53 · Un textarea de 5 filas por 30 columnas con placeholder.

25. Otros atributos de entrada

  • formnovalidate (en un submit): desactiva la validación solo para ese botón.
  • inputmode: sugiere al móvil qué teclado virtual mostrar (inputmode="numeric").
  • capture (en input type="file"): en el móvil abre directamente la cámara.
<button type="submit" formnovalidate>Guardar sin validar</button>
<input type="text" inputmode="numeric" placeholder="Código postal">
<input type="file" accept="image/*" capture="environment">

27. autocomplete

autocomplete indica al navegador si debe ofrecer rellenar el campo con datos guardados y de qué tipo de dato se trata.

  • off: desactiva las sugerencias (en el campo o, puesto en el form, en todo el formulario).
  • on: valor por defecto.
  • Valores concretos: name, email, tel, street-address, new-password, current-password… para rellenar con el perfil guardado.
<input type="text" id="nombre" name="nombre" autocomplete="name">
<input type="password" id="clave-nueva" name="clave-nueva" autocomplete="new-password">

29. Botones

<button> crea un botón pulsable, el más flexible: puede contener otras etiquetas (imagen, texto con formato). No hace falta que esté dentro de un <form>: fuera de uno no envía ni resetea nada, pero sigue siendo pulsable y se usa con JavaScript.

  • type="button": botón normal, sin comportamiento propio (funcionalidad con JavaScript, Unidad 4).
  • type="submit": dentro de un formulario, lo envía. Es el comportamiento por defecto si no se indica type.
  • type="reset": dentro de un formulario, lo borra.
<button type="button">Botón normal</button>
<button type="button"><strong>Botón</strong> con texto en negrita</button>

30. Iframes

<iframe> incrusta un documento HTML completo de otra página en un recuadro independiente (Google Maps, Spotify, YouTube).

  • src: URL de la página.
  • width y height: tamaño.
  • allowfullscreen: permite pantalla completa.
  • title: describe el contenido a los lectores de pantalla; conviene incluirlo siempre.
<iframe width="560" height="315"
        src="https://www.google.com/maps/embed?pb=..."
        title="Mapa de ubicación del instituto"
        loading="lazy"></iframe>

31. El elemento head

Reúne todo lo que el navegador y el buscador necesitan saber de la página, pero que no es contenido visible.

  • <meta charset="UTF-8">: codificación; de las primeras líneas.
  • <title>: título de la pestaña y de los resultados; obligatorio.
  • <meta name="description" content="...">: resumen que los buscadores suelen mostrar bajo el título.
  • <link rel="icon">: favicon. <link rel="stylesheet">: hoja externa. <style>: CSS interno.
  • <meta name="viewport" content="width=device-width, initial-scale=1.0">: cómo ajustar la página en móviles (diseño responsive).

- Sin él, los navegadores de móvil simulan una pantalla de unos 980 píxeles y reducen la página: hay que hacer zoom.

- name="viewport": configura el área visible de la página.

- width=device-width: usa el ancho real del dispositivo (en un móvil de 390 px, la página mide 390).

- initial-scale=1.0: zoom inicial al 100 %.

<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1.0">
  <meta name="description" content="Página personal de un estudiante.">
  <title>Mi página personal</title>
  <link rel="icon" href="favicon.ico">
  <link rel="stylesheet" href="estilos.css">
</head>

Nada de lo que hay en el head se ve directamente (salvo el título en la pestaña).

32. HTML5 semántico

Hasta HTML4 la estructura se montaba con div y clases. HTML5 añadió etiquetas que dicen qué es cada bloque, útiles para buscadores y lectores de pantalla. No cambian nada visualmente: un header se muestra igual que un div; el aspecto sigue siendo de CSS.

EtiquetaUso
<header>Cabecera de la página o sección: logo, título, menú
<nav>Bloque de enlaces de navegación principal
<main>Contenido principal; solo uno por página
<section>Contenido relacionado por tema, normalmente con su encabezado
<article>Contenido independiente (noticia, entrada de blog, producto)
<aside>Contenido secundario relacionado (barra lateral)
<footer>Pie de página o sección
<search>Región de búsqueda o filtrado (2024)
<div> / <span>Genéricos, cuando ninguna semántica encaja
<body>
  <header>
    <h1>Mi Blog</h1>
    <nav><a href="#">Inicio</a> <a href="#">Sobre mí</a></nav>
    <search>
      <form action="/buscar"><input type="search" name="q" placeholder="Buscar..."></form>
    </search>
  </header>
  <main>
    <article><h2>Primer artículo</h2><p>Contenido...</p></article>
    <aside><p>Dato relacionado.</p></aside>
  </main>
  <footer><p>&copy; 2026 Mi Blog</p></footer>
</body>

33. Emojis y símbolos

HTML reserva <, > y & para su sintaxis: para mostrarlos como texto hay que usar una entidad.

  • Con nombre: &nombre; → &lt; (<), &gt; (>), &amp; (&), &copy; (©), &euro; (€), &nbsp; (espacio que no se rompe).
  • Numérica decimal: &#8364; = €.
  • Numérica hexadecimal: &#x20AC; = €.
<p>Precio: 15 &euro; (o bien: 15 &#8364;)</p>
<p>&copy; 2026 Mi Empresa.</p>
<p>Para escribir una etiqueta: &lt;p&gt;</p>

Los emojis (😀, 🚀, ✅) no necesitan entidad: son caracteres Unicode y, con <meta charset="UTF-8">, se escriben directamente. También como entidad numérica (&#128512; = 😀).

34. Widgets HTML5 sin JavaScript

details y summary

Un bloque que se despliega al hacer clic, sin JavaScript. <details> crea el widget (cerrado por defecto; con open aparece abierto). <summary> va dentro y es lo único visible cuando está cerrado.

<details>
  <summary>¿Necesito saber programar para usar HTML?</summary>
  <p>No. HTML es un lenguaje de marcas.</p>
</details>
<details open>
  <summary>¿Puedo tener varios details?</summary>
  <p>Sí, y cada uno se abre por separado.</p>
</details>
Actividad 66 · Una FAQ con tres details/summary.

progress y meter

  • <progress value="..." max="...">: barra de progreso de una tarea en curso (descarga, formulario a medias).
  • <meter value="..." min="..." max="...">: medida dentro de un rango ya conocido (una nota, el uso del disco); no avanza con el tiempo.
<progress id="tarea" value="70" max="100"></progress>
<meter id="nota" value="7" min="0" max="10"></meter>

35. dialog

<dialog> crea una ventana modal nativa que se superpone con el fondo oscurecido: avisos, confirmaciones, formularios emergentes.

  • open: escrito en el HTML, el dialog aparece visible, pero como un bloque normal, no como ventana modal.
  • Para abrirlo como modal de verdad hace falta JavaScript: dialog.showModal() lo abre y dialog.close() lo cierra. Sin open y sin JavaScript no se ve. Se retoma en la Unidad 4.
<dialog id="aviso">
  <p>Esta acción no se puede deshacer.</p>
  <button>Cerrar</button>
</dialog>
Actividad 68 · Un dialog con mensaje y botón; pruébalo sin y con open y compara.

36. canvas

<canvas> es un lienzo en blanco sobre el que se dibuja solo con JavaScript. La etiqueta únicamente reserva el espacio (width, height) y un id. Su contenido se genera punto a punto en el momento (ideal para gráficos que cambian, juegos o visualizaciones), a diferencia de una imagen ya hecha, y distinto de SVG, que describe formas en XML.

<canvas id="miLienzo" width="200" height="100" style="border: 1px solid black;"></canvas>
<script>
  const c = document.getElementById("miLienzo");
  const ctx = c.getContext("2d");
  ctx.moveTo(0, 0);
  ctx.lineTo(200, 100);
  ctx.stroke();
</script>

En esta unidad basta reconocer la etiqueta; dibujar (getContext("2d"), moveTo, lineTo, fillRect, arc…) es de la Unidad 4.

Actividad 69 · Reserva un canvas de 300x150 con un id propio, sin dibujar.

37. Audio y vídeo

  • <audio controls>: reproduce sonido. controls muestra play, pausa y volumen.
  • <video controls>: igual con imagen. Conviene fijar width y height para que la página no salte mientras carga.
  • Dentro van uno o varios <source src type> con formatos alternativos.
<video width="480" height="270" controls>
  <source src="presentacion.mp4" type="video/mp4">
  <source src="presentacion.webm" type="video/webm">
  Tu navegador no soporta la etiqueta video.
</video>
<audio controls>
  <source src="cancion.mp3" type="audio/mpeg">
  <source src="cancion.ogg" type="audio/ogg">
</audio>

Formatos: vídeo MP4, WebM u Ogg; audio MP3, WAV u Ogg. El texto entre apertura y cierre solo se muestra si el navegador es tan antiguo que no reconoce la etiqueta.

38. Validación de documentos HTML

Un HTML con errores (etiqueta sin cerrar, atributo repetido, imagen sin alt) se muestra igual porque los navegadores son muy tolerantes, pero puede fallar en otro navegador o dar problemas de accesibilidad. El validador oficial del W3C (validator.w3.org) señala los errores exactos con su línea; admite URL, archivo o código pegado.

  • Errores típicos: etiquetas abiertas sin cerrar, atributos duplicados, imágenes sin alt, anidamiento incorrecto (un <p> dentro de otro <p>), etiquetas obsoletas.
