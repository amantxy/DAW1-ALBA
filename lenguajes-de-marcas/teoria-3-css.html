Unidad 3 · CSS: hojas de estilo, diseño y maquetación

1. Qué es CSS

CSS (Cascading Style Sheets, hojas de estilo en cascada) define el aspecto visual de una página: colores, tipos de letra, tamaños, espacios y la posición de cada elemento. HTML dice qué es cada cosa (un título, una lista, una imagen); CSS dice cómo se ve.

Sin CSS, el navegador muestra un estilo por defecto muy básico. Separar contenido (HTML) y presentación (CSS) tiene ventajas: se puede cambiar por completo el aspecto sin tocar el HTML, una misma hoja sirve para varias páginas, y el código queda más limpio. Es la idea que sustituye a las etiquetas de formato de HTML 4 (font, center, bgcolor).

A partir de CSS3 la especificación se divide en módulos (selectores, colores, flexbox, grid...) que evolucionan por separado. Por eso no se habla de «CSS4», sino de cada módulo.

Herramientas: las herramientas de desarrollador del navegador (F12, pestaña Elements) muestran qué reglas se aplican a un elemento y cuáles están tachadas. Con VS Code y la extensión Live Server ves los cambios al guardar.

2. Sintaxis de una regla y comentarios

Una hoja de estilos es una lista de reglas. Cada regla tiene un selector (a qué elementos se aplica) y un bloque de declaraciones entre llaves, con pares propiedad: valor;.

selector {
  propiedad: valor;
  propiedad2: valor2;
}

El punto y coma final es opcional, pero conviene ponerlo siempre. Los comentarios van entre /* y */; el navegador los ignora. No se usan // ni <!-- -->.

h1 {
  color: navy;
  /* font-size: 40px;  <- desactivada temporalmente */
}

3. Cómo incorporar CSS al HTML

Hay tres formas, que pueden convivir:

  • En línea: el atributo style de una etiqueta. Solo afecta a ese elemento; úsalo para pruebas o ajustes puntuales.
  • Interna: un bloque <style> dentro del <head>. Afecta a todo el documento, pero solo a ese.
  • Externa: un archivo .css enlazado con <link>. Es la forma recomendada: se reutiliza en varias páginas y el navegador la guarda en caché.
<p style="color: blue;">Solo este párrafo es azul.</p>

<head>
  <style>
    p { color: blue; }
  </style>
</head>

<!-- estilos.css -->
<link rel="stylesheet" href="estilos.css">

4. La cascada: qué regla gana

Cuando varias reglas afectan al mismo elemento, CSS decide con la cascada. Se comprueba en este orden:

  1. Origen: un estilo en línea gana a cualquier bloque interno o externo.
  2. Especificidad: cuenta el tipo de selector: #id pesa más que .clase (o atributo, o pseudo-clase), que pesa más que el elemento (p). El universal * no suma nada.
  3. Orden: si todo lo anterior empata, gana la regla que aparece más tarde (o el <link> enlazado más tarde).
p { color: black; }              /* especificidad: 1 elemento */
.aviso { color: orange; }      /* especificidad: 1 clase */
#principal { color: red; }     /* especificidad: 1 id, gana */

!important gana a todo lo anterior. Úsalo solo como último recurso, porque luego es muy difícil de sobrescribir.

Además, cada navegador trae su propia hoja por defecto (enlaces azules, títulos de distinto tamaño, listas con sangría). Tus reglas compiten con ella y, en general, la sustituyen.

5. Errores típicos y validación

El navegador es muy tolerante con CSS: si una línea está mal, la ignora en silencio y sigue con el resto. Los errores más habituales son:

  • Falta el punto y coma: la línea siguiente se toma como parte del valor.
  • Propiedad inexistente por errata (colr en vez de color).
  • Valor no válido para esa propiedad (color: 20px;): se ignora toda la declaración.
  • Llave sin cerrar: el resto de la hoja puede interpretarse mal.
  • Dos puntos seguidos (::) por error.

El validador oficial del W3C (jigsaw.w3.org/css-validator) muestra la línea exacta de cada error, en vez de dejarlo pasar en silencio.

6. Selectores

El selector decide a qué elementos se aplican las declaraciones. Cuanto más preciso, más control.

SelectorQué seleccionaEjemplo
*Todos los elementos* { margin: 0; }
elementoTodas las etiquetas de ese nombrep { color: black; }
#idEl único elemento con ese id#cabecera { ... }
.claseTodos los elementos con esa clase.destacado { ... }
elemento.claseSolo ese tipo de elemento con esa clasep.destacado { ... }
[atributo]Elementos con ese atributo (también [atributo="valor"], [atributo$="valor"])input[type="email"] { ... }

Varios selectores separados por comas comparten el mismo bloque: h1, h2, h3 { ... }.

7. Color

Se puede indicar un color de cuatro formas:

h1 { color: navy; }                  /* nombre */
h1 { color: #1F4E79; }                 /* hexadecimal */
h1 { color: rgb(31, 78, 121); }        /* rojo, verde, azul de 0 a 255 */
h1 { color: hsl(210, 60%, 30%); }      /* tono, saturación, luminosidad */

Las cuatro son el mismo azul escrito de formas distintas. hsl() es cómodo para aclarar u oscurecer un tono. La propiedad color cambia el texto; border-color, el borde (solo se ve si hay además border-style y border-width).

Opacidad: opacity afecta a todo el elemento, incluido el texto. Si solo quieres transparencia en el fondo, usa rgba() o hsla() con un cuarto valor alfa de 0 a 1.

8. Fondo

Un elemento puede tener un color de fondo o una imagen, con control sobre su repetición, posición y comportamiento al hacer scroll.

PropiedadQué controlaValores habituales
background-colorColor lisoCualquier notación de color
background-imageImagen, con url("ruta.jpg")Se repite en mosaico por defecto
background-repeatRepeticiónrepeat, no-repeat, repeat-x, repeat-y
background-positionDónde se colocacenter, top right, 50% 50%
background-attachmentSi se mueve con el scrollscroll (por defecto), fixed
background-sizeTamaño de la imagencover (cubre y recorta), contain (cabe entera)
.cabecera {
  background: navy url("textura.png") center / cover no-repeat fixed;
}

En la shorthand background el tamaño va detrás de la posición, separado por una barra (center / cover). Si no lo indicas, no escribes la barra.

9. Bordes

Un borde se define con tres propiedades: border-style (solid, dashed, dotted, double, none), border-width y border-color. Sin border-style no se ve borde, aunque tenga color y grosor. Además, border-radius redondea las esquinas; con el 50 % en un cuadrado obtienes un círculo.

.tarjeta { border: 2px solid navy; }      /* shorthand: grosor, estilo, color */
.tarjeta { border-right: 1px solid #ccc; }  /* solo un lado */
.avatar { border-radius: 50%; }

Con border-color en un div (bloque) el borde rodea todo el ancho; en un span (en línea) se ajusta al texto y, si este ocupa varias líneas, el borde se parte.

10. Márgenes y padding

margin es el espacio fuera de la caja (siempre transparente) y separa el elemento de sus vecinos. padding es el espacio dentro de la caja, entre el contenido y el borde; si el elemento tiene fondo, el padding se ve de ese color.

.tarjeta {
  margin: 20px;            /* los cuatro lados */
  padding: 10px 20px;      /* arriba/abajo, izquierda/derecha */
}
.centrado { margin: 0 auto; }  /* centra un bloque con ancho fijo */

Las medidas pueden ser px (la más habitual), cm (sobre todo para impresión), % (relativo al ancho del contenedor, también en vertical), auto (el navegador calcula; en margin sirve para centrar) e inherit (toma el valor del padre).

La shorthand va en sentido de las agujas del reloj desde arriba: uno, dos, tres o cuatro valores (arriba, derecha, abajo, izquierda). Con dos valores, el primero es arriba/abajo y el segundo derecha/izquierda.

11. Modelo de cajas y tamaño

Cada elemento es una caja con cuatro capas, de dentro hacia fuera: contenido, padding, border y margin. Las herramientas de desarrollador las dibujan con sus medidas.

Por defecto, width mide solo el contenido, así que el padding y el borde se suman al ancho. Con box-sizing: border-box el ancho incluye padding y borde, y es lo más cómodo.

.caja {
  box-sizing: border-box;
  width: 300px;
  padding: 20px;
  border: 2px solid navy;
}
.completo { width: 100%; }
.barra { min-width: 150px; max-width: 220px; }
Actividad 9 · Haz la misma caja con y sin box-sizing: border-box y compara su ancho en el inspector.

12. Outline: un borde que no ocupa espacio

outline se dibuja como un borde (outline-style, outline-width, outline-color), pero nunca forma parte del modelo de cajas: no ocupa espacio y no empuja a los elementos de alrededor. Con outline-offset se separa del borde de la caja. Por eso el navegador lo usa para marcar el elemento con foco del teclado (:focus) sin alterar la página.

button:focus {
  outline: 3px solid teal;
  outline-offset: 2px;   /* separado 2px del botón, sin cambiar su tamaño */
}

13. Texto: alineación, decoración, mayúsculas y sombra

Estas propiedades controlan el aspecto del texto, sin cambiar el HTML.

h1 { text-align: center; }            /* left, right, center, justify */
a { text-decoration: none; }         /* quita el subrayado de los enlaces */
h2 { text-transform: uppercase; }      /* uppercase, lowercase, capitalize */
h1 { letter-spacing: 2px; }            /* espacio entre letras */
p { word-spacing: 6px; }               /* espacio entre palabras */
h1 { text-shadow: 2px 2px 4px rgba(0, 0, 0, 0.3); }  /* desplazamiento X, Y, difuminado, color */

El text-transform cambia cómo se ve el texto, pero el contenido del HTML sigue igual.

14. Fuentes: pilas, web safe fonts y Google Fonts

font-family es una pila de preferencias separadas por comas. El navegador usa la primera que tenga instalada. Por eso una pila va de lo más específico a lo más genérico y termina siempre en una familia genérica (serif, sans-serif, monospace).

Las web safe fonts (Arial, Georgia, Verdana, Times New Roman, Courier New...) vienen en casi todos los sistemas, así que son buenas segundas opciones.

body {
  font-family: "Segoe UI", Arial, sans-serif;
  /* 1º Segoe UI, 2º Arial si no está, 3º cualquier sans-serif */
}

Si ninguna fuente instalada sirve, Google Fonts permite enlazar una fuente externa desde el head, igual que una hoja de estilos:

<head>
  <link rel="stylesheet" href="https://fonts.googleapis.com/css2?family=Roboto&amp;display=swap">
</head>

body {
  font-family: "Roboto", Arial, sans-serif;
}

Otras propiedades: font-size, font-weight (normal, bold o de 100 a 900), font-style y line-height. La shorthand font resume, en este orden, estilo, variante, grosor, tamaño/altura de línea y familia. Solo son obligatorios el tamaño y la familia.

p { font: italic bold 18px/1.4 "Segoe UI", sans-serif; }

15. Pseudo-clases de enlace, estructurales y combinadas

Una pseudo-clase selecciona según un estado o una posición que no está en el HTML. Se escriben con dos puntos.

a:link    { color: teal; }     /* enlace sin visitar */
a:visited { color: purple; }   /* enlace ya visitado */
a:hover   { background-color: yellow; }  /* ratón encima */
a:active  { color: red; }      /* mientras se pulsa */
a:focus   { outline: 2px solid teal; } /* foco del teclado (Tab) */

Cuando se combinan, el orden importa: link, visited, hover, active (la regla LoVe/HAte). Así hover y active ganan por aparecer después.

Pseudo-clases estructurales, según la posición entre hermanos: :first-child, :last-child y :nth-child(n), que admite odd (impares), even (pares) o un número.

li:first-child { font-weight: bold; }
li:last-child  { color: gray; }
li:nth-child(odd) { background-color: #F2F4F6; }

Un selector puede encadenar pseudo-clases sin espacios para exigir que se cumplan todas: a.boton:visited:hover solo se aplica a un enlace ya visitado y con el ratón encima.

a.boton { display: inline-block; padding: 10px 20px; background-color: teal; color: white; text-decoration: none; border-radius: 6px; }
a.boton:hover { background-color: #1F4E79; }
a.boton:visited:hover { background-color: #5B6B75; }

16. display: block, inline, inline-block y none

display decide cómo se representa un elemento y cómo se apila. Un div es block por defecto y un a es inline.

block ocupa todo el ancho y empieza en línea nueva. Acepta width, height y margin/padding en todas las direcciones. inline ocupa solo su contenido y no acepta width ni height. inline-block se coloca en línea como un inline, pero acepta width, height y todo el margin/padding como un block: es el valor para convertir enlaces en botones con tamaño fijo. none quita el elemento del todo: no ocupa espacio.

a.boton { display: inline-block; width: 120px; padding: 10px; text-align: center; }
span.oculto { display: none; }

Grid y flexbox también son valores de display, que se ven con detalle en las unidades 3.2 y 3.3.

Visibilidad: visibility frente a display

visibility: hidden oculta el elemento pero conserva su hueco. display: none lo oculta y lo quita también del espacio.

.a { visibility: visible; border: 2px solid navy; }
.b { visibility: hidden;  border: 2px solid navy; }  /* invisible, con hueco */
.c { display: none;       border: 2px solid navy; }  /* invisible, sin hueco */

Un uso típico de visibility: hidden: reservar el espacio de un mensaje de error que aparecerá después, para que el resto de la página no salte de sitio.

17. max-width y diseño adaptable

Fijar solo width tiene dos problemas: en una pantalla estrecha el elemento se desborda, y en una ancha sobra espacio sin aprovechar.

.contenedor {
  width: 100%;
  max-width: 800px;   /* nunca supera 800px, pero se encoge sin problema */
  margin: 0 auto;     /* centrado */
}

max-width deja crecer el elemento hasta ese límite y nunca lo supera. Combinado con width: 100% y margin: 0 auto, es el patrón más habitual del contenedor principal de una página adaptable.

Actividad · Un contenedor de ancho fijo se desborda en una ventana estrecha. Hazlo adaptable sin que supere un máximo razonable en pantallas grandes.

18. Posicionamiento: static, relative, absolute, fixed y sticky

position cambia cómo se coloca un elemento respecto al flujo normal. Afecta al propio elemento (desde dónde se calculan sus coordenadas) y a los que tiene alrededor (si dejan hueco o no).

div { position: static; }    /* por defecto: flujo normal, top/left no tienen efecto */
img.aviso { position: relative; top: 10px; left: 10px; }  /* se desplaza, deja hueco */
div.tarjeta { position: relative; }
span.insignia { position: absolute; top: 0; right: 0; }  /* sale del flujo, sin hueco */
header.barra { position: fixed; top: 0; left: 0; width: 100%; }  /* fijo en la ventana */
h2.cabecera-seccion { position: sticky; top: 0; background-color: white; }

relative deja su hueco y se desplaza desde él. absolute sale del flujo y se posiciona respecto a su antecesor posicionado más cercano (el primero con relative, absolute o fixed). fixed es como absolute, pero respecto a la ventana, así que se queda quieto al hacer scroll. sticky se comporta como relative hasta que, al hacer scroll, alcanza el top indicado, y entonces se queda fijo mientras dura su contenedor.

19. Offset y z-index

top, right, bottom y left fijan la distancia de un elemento posicionado a su referencia. Su efecto depende del tipo de position:

/* relative: se desplaza, pero su hueco original queda vacío */
img.foto { position: relative; top: 8px; left: 8px; }

/* absolute o fixed: no queda ningún hueco en el flujo */
div.tarjeta { position: relative; }
span.insignia { position: absolute; top: 0; right: 0; }

z-index decide qué elemento queda por encima cuando se solapan: un número mayor queda más arriba. Solo funciona en elementos posicionados (cualquier position distinto de static).

.fondo    { position: relative; z-index: 1; }
.tarjeta  { position: relative; z-index: 2; }
.insignia { position: absolute; z-index: 3; top: -10px; right: -10px; }
.modal    { position: fixed;    z-index: 100; }  /* siempre arriba */

20. Overflow: los cuatro valores

Cuando el contenido no cabe en una caja de tamaño fijo, overflow decide qué pasa con lo que sobra.

.caja-visible { height: 80px; overflow: visible; }  /* se sale igualmente */
.caja-hidden  { height: 80px; overflow: hidden; }   /* desaparece el sobrante */
.caja-scroll  { height: 80px; overflow: scroll; }   /* barra siempre visible */
.caja-auto    { height: 80px; overflow: auto; }     /* barra solo si hace falta */

auto es el valor que más se usa en la práctica.

21. Barras de navegación

Una barra de navegación es una lista de enlaces dentro de un nav. En CSS se convierte en una fila o una columna quitando los marcadores y colocando los elementos.

nav ul { list-style: none; margin: 0; padding: 0; background-color: navy; }
nav li { display: inline-block; }      /* fila horizontal */
nav a {
  display: block;
  padding: 14px 20px;
  color: white;
  text-decoration: none;
}
nav a:hover { background-color: #2E86AB; }

Para convertirla en columna vertical basta con quitar el display: inline-block de los li: cada uno ocupa su propia fila.

22. Menús desplegables (dropdown)

Un submenú oculto aparece al pasar el ratón por su elemento padre, sin JavaScript. Se apoya en :hover y en un selector descendiente. El padre necesita position: relative para que el submenú (absolute) se coloque bajo él.

nav li { position: relative; }
nav .submenu {
  display: none;          /* oculto por defecto */
  position: absolute;
  top: 100%;              /* justo debajo del padre */
  left: 0;
  background-color: navy;
  min-width: 160px;
}
nav li:hover .submenu { display: block; }

23. Estilos para formularios

Los campos se seleccionan como cualquier elemento (por tipo, atributo o clase) y admiten casi todas las propiedades vistas.

input[type="text"], input[type="email"], textarea {
  padding: 8px;
  border: 1px solid #C7D1D9;
  border-radius: 4px;
  width: 100%;
}
input[type="checkbox"] { width: 18px; height: 18px; margin-right: 8px; }
select { padding: 8px; border: 1px solid #C7D1D9; border-radius: 4px; }
input[type="submit"] { background-color: navy; color: white; border: none; padding: 10px 24px; border-radius: 4px; }
input[type="submit"]:hover { background-color: #2E86AB; }
input:focus, textarea:focus, select:focus { border-color: teal; outline: none; }

Las casillas admiten pocos cambios porque el navegador controla buena parte de su apariencia. El foco conviene marcarlo siempre, con un color de borde o con outline.

24. Herencia

Algunas propiedades se heredan de forma natural del padre si el elemento no las define: color, font-family, font-size, line-height, text-align. Otras no se heredan nunca: las del modelo de cajas (margin, padding, border, width) y casi todas las de posicionamiento.

La herencia atraviesa varios niveles. El valor inherit fuerza a cualquier propiedad a tomar el valor de su padre, herede o no por defecto.

article { color: #1F4E79; font-family: Georgia, serif; }
/* <p>, <div> y <span> dentro del article heredan color y fuente */

button { border-color: inherit; }  /* fuerza la herencia de una propiedad no heredable */
Actividad · Define color y font-family en el body de una página con varios niveles anidados y comprueba hasta dónde llega la herencia. Después define margin y border en un div padre y comprueba que un hijo no los hereda.

25. Diseño de página completa

Combinando lo visto se construye la estructura de una página: cabecera, navegación, contenido principal, barra lateral y pie.

<body>
  <header>Mi sitio</header>
  <nav><ul><li><a href="#">Inicio</a></li><li><a href="#">Contacto</a></li></ul></nav>
  <div class="cuerpo">
    <aside>Barra lateral</aside>
    <main>Contenido principal</main>
  </div>
  <footer>Pie de página</footer>
</body>
header, footer { background-color: navy; color: white; padding: 20px; text-align: center; }
.cuerpo { display: flex; }      /* adelanto de flexbox */
aside { width: 220px; background-color: #F2F4F6; padding: 20px; }
main  { flex: 1; padding: 20px; }  /* ocupa el resto del espacio */

Las tres decisiones clave: cabecera y pie de ancho completo, la nav como barra horizontal con las técnicas de este tema, y un contenedor .cuerpo con una barra lateral de ancho fijo y un main que ocupa el resto.
