UT 10. Windows en red

Desarrollado a partir de la programación. Algunas funciones solo están en Windows Server. Se ampliará con lo que añada el profesor.

1. Configurar la redipconfig y PowerShell
ipconfig /all
Get-NetAdapter
Get-NetIPConfiguration
New-NetIPAddress -InterfaceAlias "Ethernet" -IPAddress 192.168.1.60 -PrefixLength 24 -DefaultGateway 192.168.1.1
Set-DnsClientServerAddress -InterfaceAlias "Ethernet" -ServerAddresses 1.1.1.1,8.8.8.8
Set-NetIPInterface -InterfaceAlias "Ethernet" -Dhcp Enabled

Gráfico: Configuración → Red e Internet, o ncpa.cpl.

3. EnrutamientoTablas de rutas
route print
route add 10.0.0.0 mask 255.255.255.0 192.168.1.1
route -p add 10.0.0.0 mask 255.255.255.0 192.168.1.1
Get-NetRoute

-p hace que la ruta sobreviva al reinicio.

4. Compartir archivos e impresorasSMB
New-SmbShare -Name "Compartido" -Path "C:\Compartido" -ChangeAccess "alumno"
Get-SmbShare
net use Z: \\SERVIDOR\Compartido
Get-Printer

Se aplica lo más restrictivo entre los permisos del recurso compartido y los de NTFS. Windows Server añade roles de servidor de archivos, de impresión y web (IIS) desde el Administrador del servidor.

5. Acceso remoto y cortafuegosRDP, OpenSSH y reglas
  • Escritorio remoto (RDP): mstsc. Puerto 3389.
  • OpenSSH: se añade como característica opcional.
  • PowerShell remoto: Enter-PSSession.
Add-WindowsCapability -Online -Name OpenSSH.Server~~~~0.0.1.0
Start-Service sshd
Set-Service sshd -StartupType Automatic

Cortafuegos, gráfico en wf.msc:

Get-NetFirewallProfile
New-NetFirewallRule -DisplayName "Web" -Direction Inbound -Protocol TCP -LocalPort 80 -Action Allow
Remove-NetFirewallRule -DisplayName "Web"

Dominios
