UT 9. Linux en red

Desarrollado a partir de la programación. Cambiar la red puede dejarte sin conexión: hazlo desde la consola de la VM. Se ampliará con lo que añada el profesor.

1. Configurar la redip y netplan
ip a
ip route
resolvectl status
sudo ip link set enp0s3 up

Ubuntu Server guarda la red en /etc/netplan/*.yaml. Ejemplo de IP fija:

network:
  version: 2
  ethernets:
    enp0s3:
      addresses: [192.168.1.50/24]
      routes:
        - to: default
          via: 192.168.1.1
      nameservers:
        addresses: [1.1.1.1, 8.8.8.8]
sudo netplan try
sudo netplan apply

netplan try vuelve atrás solo si no confirmas, así que es la opción segura. Los nombres son ejemplos: mira los tuyos con ip a.

3. EnrutamientoPasar paquetes entre redes
ip route
sudo ip route add 10.0.0.0/24 via 192.168.1.1
sudo sysctl -w net.ipv4.ip_forward=1

Las dos últimas duran hasta reiniciar. Para hacerlas permanentes: la ruta en netplan y el reenvío en /etc/sysctl.d/.

4. Recursos compartidos e impresiónSamba, NFS y CUPS
sudo apt install samba
sudo mkdir -p /srv/compartido
sudo nano /etc/samba/smb.conf
[compartido]
   path = /srv/compartido
   read only = no
   valid users = alumno
sudo smbpasswd -a alumno
sudo systemctl restart smbd

Desde Windows se entra con \\192.168.1.100\compartido. Para red entre Linux está NFS, y para imprimir, CUPS. Como servidor de aplicaciones web, por ejemplo Nginx o Apache.

5. Acceso remoto y cortafuegosSSH y ufw
ssh alumno@192.168.1.100
ssh-keygen -t ed25519
ssh-copy-id alumno@192.168.1.100

En /etc/ssh/sshd_config, PermitRootLogin no y, si ya usas claves, PasswordAuthentication no.

sudo ufw allow OpenSSH
sudo ufw allow 80/tcp
sudo ufw enable
sudo ufw status numbered
sudo ufw deny 23

Permite OpenSSH antes de activar ufw, o te quedarás fuera si estás conectado por SSH.

Dominio

Un equipo Linux puede unirse a un dominio de Windows con realmd:

sudo realm join empresa.local -U administrador
