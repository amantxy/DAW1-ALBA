UT 5. Linux para usuarios

Desarrollado a partir de la programación, para practicar en tu Ubuntu Server. Se ampliará con lo que añada el profesor.

1. Moverse por el sistemaRutas y directorios
pwd
ls -la
cd /etc
cd ~
mkdir -p proyectos/daw

Ruta absoluta empieza por /. Relativa parte de donde estás. . es aquí, .. el padre y ~ tu carpeta.

2. ArchivosCopiar, mover, ver
ComandoHace
touch a.txtCrea un archivo vacío
cp a.txt b.txtCopia
mv a.txt c.txtMueve o renombra
rm b.txtBorra, sin papelera
rm -r carpetaBorra una carpeta entera
cat, lessMuestra el contenido
head, tail -fPrincipio y final en vivo
nano a.txtEdita
3. Búsqueda y filtrosfind, grep y tuberías
find /etc -name "*.conf"
find ~ -type f -size +10M
grep -i "error" /var/log/syslog
grep -r "ssh" /etc/ssh
ls -l | wc -l
ps aux | grep ssh
echo "hola" > a.txt
echo "más" >> a.txt

| pasa la salida a otro comando. > sobrescribe un archivo y >> añade al final.

4. Software instaladoapt y snap
apt list --installed | less
sudo apt update
sudo apt upgrade
sudo apt install tree
sudo apt remove tree
apt search editor
snap list
5. Copias y tareas automáticastar, rsync y cron
tar -czf copia.tar.gz proyectos/
tar -xzf copia.tar.gz
rsync -av proyectos/ /mnt/copia/proyectos/
crontab -e

Cada línea de cron tiene: minuto, hora, día, mes, día de la semana y comando.

30 2 * * 1 tar -czf /home/alumno/copia.tar.gz /home/alumno/proyectos

Se ejecuta los lunes a las 2:30.

6. Documentación, ofimática y correoLo que usa un usuario
  • Ayuda: man ls, ls --help.
  • Ofimática: LibreOffice en escritorio.
  • Correo: clientes como Thunderbird; en servidor, mail.
  • Transferir ficheros: scp, sftp, rsync.
scp informe.pdf alumno@192.168.1.100:/home/alumno/
sftp alumno@192.168.1.100
7. EjerciciosCon solución
  1. Crea ~/daw/ut5 en un solo comando y entra.
  2. Crea notas.txt con la palabra «linux» dentro.
  3. Busca todos los .log de /var/log.
  4. Cuenta cuántas líneas de /etc/passwd contienen bash.
  5. Comprime ~/daw en daw.tar.gz.
  6. Programa esa copia para cada día a las 23:00.
Ver la solución
mkdir -p ~/daw/ut5 && cd ~/daw/ut5
echo "linux" > notas.txt
sudo find /var/log -name "*.log"
grep -c bash /etc/passwd
tar -czf ~/daw.tar.gz -C ~ daw
crontab -e
0 23 * * * tar -czf /home/alumno/daw.tar.gz -C /home/alumno daw

La última línea va dentro del editor de crontab. En cron, mejor usa rutas completas.
