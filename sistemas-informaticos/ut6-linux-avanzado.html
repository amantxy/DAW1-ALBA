UT 6. Linux avanzado

Desarrollado a partir de la programación. Prueba estos comandos solo en una máquina virtual: algunos borran datos. Se ampliará con lo que añada el profesor.

1. Discos, particiones y volúmeneslsblk, LVM y montaje
lsblk
sudo fdisk -l
df -h
sudo mkfs.ext4 /dev/sdb1
sudo mount /dev/sdb1 /mnt
sudo blkid

Para montar al arrancar, se añade a /etc/fstab:

UUID=xxxx-xxxx /datos ext4 defaults 0 2

LVM

Volumen físico (PV)Grupo de volúmenes (VG)Volumen lógico (LV)
sudo pvcreate /dev/sdb1
sudo vgcreate datos-vg /dev/sdb1
sudo lvcreate -L 5G -n lv-datos datos-vg
sudo lvextend -r -L +1G /dev/datos-vg/lv-datos

Chequeo y cifrado

  • sudo fsck /dev/sdb1, con el sistema de archivos desmontado.
  • sudo smartctl -a /dev/sda, salud del disco físico.
  • LUKS cifra una partición con cryptsetup luksFormat. Se pierde lo que hubiera.

id ana
sudo passwd ana
sudo chage -l ana

Buenas prácticas: contraseñas largas, sudo en vez de root, y bloquear cuentas que no se usan con sudo usermod -L ana.

6. EjerciciosCon solución
  1. Crea el grupo daw y el usuario ana, que pertenezca a él.
  2. Crea /srv/daw, de root:daw, donde el grupo pueda escribir y los demás no vean nada.
  3. Da a pepe lectura en un archivo con ACL, sin cambiar el grupo.
  4. ¿Qué permisos da chmod 750?
  5. Haz que ana tenga que cambiar la contraseña cada 90 días.
  6. Muestra los errores del servicio ssh.
Ver la solución
sudo addgroup daw
sudo adduser ana
sudo usermod -aG daw ana
sudo mkdir /srv/daw
sudo chown root:daw /srv/daw
sudo chmod 770 /srv/daw
sudo setfacl -m u:pepe:r archivo.txt
sudo chage -M 90 ana
journalctl -u ssh -p err

El ejercicio 4: rwxr-x---. Propietario todo, grupo leer y entrar, resto nada.
